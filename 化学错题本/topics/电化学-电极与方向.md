# 电化学·电极与方向

> 归入：「谁是负极/阴极」「电子走向」「膜与对调」「牺牲阳极」
> 本主题错题：T13 T14 T15（3 题，含年级最低的 T14 47.2%）

## 一、三张表定生死

### 表 1 · 装置类型

| 装置 | 判断 | 负极/阳极 | 电解液 |
|---|---|---|---|
| 原电池 | 自发的氧化还原 | 活泼金属失电子 | — |
| 电解池 | 接电源 | 阳极接**正极**，阴极接**负极** | — |
| 牺牲阳极保护法 | 被保护金属做**正极（阴极）**，牺牲金属做负极 | 牺牲极（Zn/Mg） | 海水 |

### 表 2 · 电极反应写法（酸性/碱性两套）

| 体系 | 负极/阳极 | 正极/阴极 |
|---|---|---|
| 吸氧腐蚀（中性/碱性，pH≥5.6） | O₂ + 4e⁻ + 2H₂O = 4OH⁻（**在正极**） | 金属 − ne⁻ = Mⁿ⁺ |
| 析氢腐蚀（酸性） | 2H⁺ + 2e⁻ = H₂ | 金属 − ne⁻ = Mⁿ⁺ |
| 氯碱工业 | 阳极 2Cl⁻ − 2e⁻ = Cl₂ | 阴极 2H₂O + 2e⁻ = H₂ + 2OH⁻ |

### 表 3 · 电子/离子流向

- **外电路**：电子从负极(阳极) → 正极(阴极)；电流方向相反
- 原电池中"电子从 X 电极流向 Y 电极"→ 要在图上先确定谁失电子
- **内电路**：阳离子向正极(阴极)移，阴离子向负极(阳极)移

## 二、错题逐条

### T13 钢闸门接锌板（74.6%）

- A 牺牲阳极的阴极保护法 ✓
- B 钢闸门是**正极（阴极）**，海水弱碱性 → 吸氧腐蚀正极：O₂ + 4e⁻ + 2H₂O = 4OH⁻ ✓
- C 锌被消耗 → 需定期更换 ✓
- D **"锌板发生 Zn − 2e⁻ = Zn²⁺" ✗** —— 为什么？
  > 海水 pH 8.5，c(OH⁻)≈10⁻⁵·⁵，**Ksp[Zn(OH)₂]=3×10⁻¹⁷ → c(Zn²⁺) ≤ 3×10⁻¹⁷/(10⁻⁵·⁵)² ≈ 3×10⁻⁶ << 1**
  > 也就是说 Zn²⁺ 一旦产生就立刻沉淀，电极反应必须写成：
  > **Zn − 2e⁻ + 2OH⁻ = Zn(OH)₂**（或 Zn − 2e⁻ = Zn²⁺ 后被 Ksp 限制）
  > 题给 Ksp 就是让你算这一点的 → **答案 D**

> 🚩 **凡题干给了 Ksp/给定 pH，十有八九是为了让你把"生成沉淀"写进电极式。**

### T14 离子交换膜提锂（47.2% ★最难）

装置：**电源**接两根电极，左室（卤水）有 FePO₄ / Ag，右室（淡水）有 AgX / LiFePO₄，中间离子交换膜。

| 室 | 电极 | 反应 |
|---|---|---|
| 左·a | FePO₄ | **FePO₄ + Li⁺ + e⁻ = LiFePO₄**（嵌锂，还原，作阴极） |
| 左·c | Ag | Ag − e⁻ + X⁻ = AgX（结合 X⁻，氧化，作阳极） |
| 右·d | AgX | **AgX + e⁻ = Ag + X⁻**（脱 X⁻进入淡水） |
| 右·b | LiFePO₄ | **LiFePO₄ − e⁻ = FePO₄ + Li⁺**（锂释放进淡水） |

- A 左室 a 极嵌锂 ✓
- B AgX 极还原释 X⁻、Ag 极氧化结 X⁻ ✓（"分别"顺序对）
- C 电极对调可继续提锂 ✓（这是该工艺的巧妙处：材料可循环）
- D **充分电解后再把电源正负极对调** → 相当于**反向电解**，把已富集到淡水的 Li⁺ 又"抽"回去，淡水 c(Li⁺) **减小** ✗ → 答案 **D**

> 🚩 **"对调电源" 类选项的心法**：正负极一对调，所有电极反应全部反写，原方向"富集"就变成"释放"。
> 本题 C 的"电极对调"（换位置，不换电源）与 D 的"电源对调"是两回事——这是命题人埋的钩子。

### T15 自制电池 K₁/K₂（81.0%）

U 形管两支石墨，中间装**滴有酚酞的饱和 NaCl 溶液**，外接 K₁/K₂ 两个开关：
- ① 打开 K₂ 闭合 K₁：**外接电源，电解**（两石墨接正负极）→ 两极都产气
- ② 打开 K₁ 闭合 K₂：**断开电源、短接两极，构成原电池**

- A ① 电解：阳极上 **Cl⁻ 优先于 OH⁻ 失电子**（浓度高 + 电压不够高）→ 石墨(I) 氧化 ✓
- B ① 阴极 2H₂O + 2e⁻ = H₂ + 2OH⁻ → 附近**酚酞变红** ✓
- C ② 原电池：石墨(I) 吸附了 Cl₂，石墨(II) 吸附了 H₂，H₂ 作负极 → **电子从石墨(II) 流向石墨(I)** ✓
- D ② 中石墨(II) 是**负极**，H₂ 失电子，**碱性环境**应写：**H₂ − 2e⁻ + 2OH⁻ = 2H₂O**，而不是生成 H⁺ ✗ → 答案 **D**

> 🚩 **介质决定产物**：碱性介质中绝不出 H⁺、酸性介质中绝不出 OH⁻。写完后 5 秒自查。

## 三、一句话复盘

> 电化学只有三步：**定装置 → 定电极 → 按介质写式子**。
> 所有"Ksp/给定 pH"都是提示：**离子会沉淀，式子要带沉淀**。
