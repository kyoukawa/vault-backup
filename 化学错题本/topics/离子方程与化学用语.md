# 离子方程与化学用语

> 归入：「判断方程式书写对错」——本卷 7 题，全是"判断：对 F / 错"型
> 本主题错题：T11 T16 T17 T27 T29–T34（共 8 题，其中 T33 蔗糖水解年级仅 39.6%）

## 一、写方程式的五条铁律

1. **拆不拆**：强酸强碱可溶盐**拆**；弱酸弱碱、水、沉淀、气体、氧化物、单质**不拆**
2. **电荷守恒**：两边电荷代数和相等（写完必查）
3. **原子守恒**：写完必查
4. **介质一致**：酸性环境不出 OH⁻，碱性环境不出 H⁺
5. **"少量/过量"决定产物**：
   - 少量 CO₂ 通入苯酚钠 → 生成 **CO₃²⁻**（不是 HCO₃⁻）
   - 少量 CO₂ 通入 NaClO → 生成 **HCO₃⁻**（因 HClO 酸性强于 HCO₃⁻ 弱于 H₂CO₃）
   
   > 通用方法：**先找出"以少定多"**，少的那种按 1 mol 配平系数。

## 二、错题逐条（7 道判断题全部答案 F）

### T29 电解饱和食盐水（86.3%）— F

原式：`Cl⁻ + H₂O --电解--> Cl₂↑ + H₂↑ + OH⁻`
**错在三个地方**：
- 未配平（电荷、原子）
- 阳极产物 Cl₂、阴极产物 H₂ 混写在一个式子里
- 正确写法：
  - 阳极：`2Cl⁻ − 2e⁻ = Cl₂↑`
  - 阴极：`2H₂O + 2e⁻ = H₂↑ + 2OH⁻`
  - 总：`2Cl⁻ + 2H₂O --电解--> Cl₂↑ + H₂↑ + 2OH⁻`

### T30 FeS 除 Hg²⁺（92.1%）— F

原式：`S²⁻ + Hg²⁺ = HgS↓`
**错在**：FeS 是**难溶物**，不能拆成 S²⁻，应写**沉淀转化**：
`FeS(s) + Hg²⁺ = HgS(s) + Fe²⁺`
（K = Ksp(FeS)/Ksp(HgS) 极大，可自发）

### T31 FeBr₂ 通足量 Cl₂（81.8%）— F

原式：`2Fe²⁺ + Cl₂ = 2Fe³⁺ + 2Cl⁻`
**错在**：**足量 Cl₂ 会同时氧化 Br⁻**，还原性 Fe²⁺ > Br⁻ 但足量时都氧化：
`2Fe²⁺ + 4Br⁻ + 3Cl₂ = 2Fe³⁺ + 2Br₂ + 6Cl⁻`
（少量 Cl₂ 时才是先氧化 Fe²⁺）

### T32 苯酚钠通少量 CO₂（86.2%）— F

原式：`2C₆H₅O⁻ + H₂O + CO₂ → 2C₆H₅OH + CO₃²⁻`
**检查电荷**：左边 2×(−1) = −2，右边 0 ✗！
正确：`C₆H₅O⁻ + H₂O + CO₂ = C₆H₅OH + HCO₃⁻`（少量 CO₂ 时仍生成 HCO₃⁻，因为 **C₆H₅OH 的 Ka(≈10⁻¹⁰) 小于 HCO₃⁻**）

> 🚩 **电荷守恒是 5 秒钟就能查出来的送分项**，很多人直接跳过。写完必查！

### T33 蔗糖水解（39.6% ★）— F

原式：`C₁₂H₂₂O₁₁ + H₂O --酸或酶--> 2C₆H₁₂O₆（葡萄糖）`
**错在**：蔗糖水解产物是 **一分子葡萄糖 + 一分子果糖**（同分异构体，但**不是同一种物质**）：
`C₁₂H₂₂O₁₁ + H₂O --H⁺ 或 酶--> C₆H₁₂O₆(葡萄糖) + C₆H₁₂O₆(果糖)`
- **只有麦芽糖/淀粉/纤维素**水解才得"2 个/多个葡萄糖"

> 年级仅 39.6%，说明**这是全场最反直觉的一题**：写成两个葡萄糖，式子"原子"完全对得上，但物质错了。

### T34 实验室制 NH₃（90.2%）— F

原式：`NH₄Cl --△--> NH₃↑ + HCl↑`
**错在**：
- 单独的 NH₄Cl 受热分解，但 **NH₃ 与 HCl 遇冷立即重新化合**，收集不到 NH₃
- 正确：`2NH₄Cl + Ca(OH)₂ --△--> CaCl₂ + 2NH₃↑ + 2H₂O`（工业/实验室标准法）
- 另外，干燥 NH₃ 不能用浓硫酸，用碱石灰

### T16 覆铜板制 PCB（58.0%）— F

原式：`Fe + Cu²⁺ = Fe²⁺ + Cu`
**错在**：
- 工业上制 PCB 用 **FeCl₃** 蚀刻：`2Fe³⁺ + Cu = 2Fe²⁺ + Cu²⁺`
- 若用 Fe 直接置换 Cu²⁺，则 Fe 也会与 Cu 沉积掉，无法选择性蚀刻；且 Fe 在 Cu²⁺ 溶液中会置换，实际操作是 FeCl₃ 溶液

> 这题容易"觉得式子是配平的所以对"——**配平 ≠ 符合实际工艺**。

### T17 Ag(NH₃)₂⁺ 溶解 AgCl（81.8%）— F

原式：`Ag⁺ + 2NH₃ = [Ag(NH₃)₂]⁺`
**错在**：AgCl 是**沉淀**，不能拆成 Ag⁺：
`AgCl(s) + 2NH₃ ⇌ [Ag(NH₃)₂]⁺ + Cl⁻`

### T11 劳动项目四方程式（92.3%）→ 答案 D

- A `2Fe³⁺ + Cu = 2Fe²⁺ + Cu²⁺` ✓
- B `Al(OH)₃ + 3H⁺ = Al³⁺ + 3H₂O` ✓
- C `Fe − 2e⁻ = Fe²⁺` ✓（船体铁是负极，被氧化）
- D `2Fe + 3H₂O(高温) = Fe₂O₃ + 3H₂` ✗ —— 高温下钢水与 H₂O 生成的是 **Fe₃O₄**（或用 Fe + H₂O = FeO + H₂），**Fe₂O₃ 不稳定会被 H₂ 还原**；按命题人答案 D 是错项 → 答案 **D**

### T27 NH₃ 催化氧化（59.5%）— F

原式：`4NH₃ + 5O₂ --催化剂/△--> 4NO₂ + 6H₂O`
**错在**：产物是 **NO**，不是 NO₂：
`4NH₃ + 5O₂ --Pt/△--> 4NO + 6H₂O`
（NO 再与 O₂ 生成 NO₂，是第二步）

## 三、写完后 10 秒自检清单

```
□ 电荷守恒？仰头数一遍
□ 原子守恒？
□ 介质对？（酸不出 OH⁻、碱不出 H⁺）
□ 固/难溶物拆了没有？
□ 少量还是过量？产物选对没有？
□ "实验/工业"实际是不是这么干的？
```

## 四、一句话复盘

> 本卷 7 道判断题**全部答案 F** —— 这是命题人故意的：**每一道都长得很像对的**。
> 做题时，先假设"它对"，再找它错在哪；找不到错才敢判 F。
