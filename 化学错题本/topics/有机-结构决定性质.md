# 有机·结构决定性质

> 归入：「杂化」「键角」「极性分子」「手性碳」「水溶性」
> 本主题错题：T06 T08（2 题）

## 一、判据表（背下来就够用）

| 判断 | 结论 |
|---|---|
| sp³ | 4 个单键，键角约 **109°28′**（正四面体） |
| sp² | 1 双键 + 2 单键，键角 **120°**（平面三角） |
| sp | 1 三键/2 双键，键角 **180°**（直线） |
| **杂原子（S、O、N）** | 两个单键 + 两对孤对电子 → **sp³**（V 形，如 H₂O、R–S–R′） |
| 共价化合物 vs 离子化合物 | 阳离子是 NH₄⁺、有机胺（R₃NH⁺）盐 → 离子化合物；全是有机基团 → 共价 |
| 极性分子 | 正负电中心**不重合**；对称结构（对位二取代苯、CCl₄、CO₂）→ 非极性 |
| 手性碳 | 连 **4 个不同基团**；**sp² 碳不可能是手性碳** |
| 水溶性 | −OH、−COOH、−NH₂ 越多越溶；**形成离子（盐）后水溶性大幅提高**；烃基越大越不溶 |

## 二、错题逐条

### T06 巯基化合物（71.7%）

I：CH₂(SH)–CH(SH)–CH₂OH　　II：CH₂(SH)–CH(SH)–CH₂SO₃Na

- **A S 原子 sp³**：S 连 2 个原子 + 2 对孤对 → sp³ ✓（跟 O 一样算）
- B C—C—C 键角 180°：中间 C 是 **sp³**，键角约 109°，✗
- C **II 含 −SO₃Na，是钠盐 → 离子化合物**，不是共价化合物 ✗
- D II 是盐，水溶性 **强于** I ✗
- → **答案 A**

> 🚩 两个连招：**"含 Na 的有机物 = 盐 = 离子化合物"**；**"成盐后水溶性变好"**。

### T08 双酚 A（85.3%）

结构：HO–C₆H₄–C(CH₃)₂–C₆H₄–OH（两个对位羟基，中间 C 连两个 CH₃）

- **A "是非极性分子"**：分子有 **2 个 phenolic O–H**，方向相反但 −C(CH₃)₂− 中心 sp³，两个苯环不共面；更重要的是 O–H 极性很强 → **整体是极性分子** ✗ ← 答案
- B 中间 C 连 2 个 CH₃ → 有两个相同基团 → **不是手性碳** ✓
- C 电负性 O > C，键极性 O—H > C—H ✓
- D 与 NaOH 成 **酚钠盐**，水溶性增强 ✓

> 🚩 判极性分子的三步：① 列出所有极性键；② 看空间是否中心对称；③ 对称则抵消。双酚 A **不对称**（两个苯环可以旋转、非平面）→ 极性。

## 三、一句话复盘

> 结构题几乎都在考两件事：**中心原子的杂化（决定键角）** 和 **分子整体对称性（决定极性/水溶性）**。
