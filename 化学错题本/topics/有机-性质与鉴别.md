# 有机·性质与鉴别

> 归入：「哪些物质能用什么试剂鉴别」「官能团有哪些、能发生什么反应」
> 本主题错题：T01 T02 T04 T10 T12（5 题）

## 一、必备判据

### 1. 酸性 KMnO₄ 到底"识"什么
能氧化 → 褪色。常见四类：

- **碳碳双/三键**（烯、炔、油酸）
- **苯环上的侧链**（连 H 的 α-C，如甲苯）
- **醛基** −CHO、**羟基**（醇、酚）、甲酸及其酯
- **还原性无机物**：Fe²⁺、SO₂/SO₃²⁻、I⁻、H₂O₂

> ⚠️ 硬脂酸（C₁₇H₃₅COOH）是饱和脂肪酸，**不褪色**；油酸（有一个 C=C）褪色 → 所以选 A 能鉴别。

### 2. 常见鉴别试剂对照

| 试剂 | 现象 | 用来区分 |
|---|---|---|
| 溴水（Br₂/CCl₄） | 褪色并分层 vs 只褪色 | 烯/炔（加成） vs 醛/酚（反应） |
| 新制 Cu(OH)₂（碱过量，沸水浴） | 砖红沉淀 | 醛基、甲酸、甲酸酯、葡萄糖、麦芽糖 |
| 银氨溶液（水浴） | 银镜 | 同上 |
| FeCl₃ 溶液 | 显紫色 | 酚羟基 |
| NaHCO₃ | 放 CO₂ | −COOH（酚、醇不行） |
| 石蕊 | 变红 | 酸性物质 |
| 溴水/酸性 KMnO₄ + 苯环侧链 | 苯环侧链褪色，苯本身不褪 | 苯 vs 甲苯 |

**"都能褪色于是不能鉴别"是陷阱**——鉴别要求**一个褪色一个不褪**。

## 二、结构 → 性质 的固定推导链

```
数官能团 → 判能否与H₂/NaOH/Na/NaHCO₃/Br₂/KMnO₄ 反应
        → 判水解产物 → 判能否缩聚/加聚
```

### 高频易错

1. **羟基类型决定酸性**：酚羟基 > 醇羟基；只有酚羟基显色 FeCl₃、只有 −COOH 放 CO₂。
2. **酯基在碱性下水解**，所以"能否长期接触碱性物质"要查有没有酯/酰胺/酚羟基。
3. **手性碳**：四个基团全不同。**苯环上的碳不可能是手性碳**（sp²）。
4. **氯代环己烷等环状物 → 消去**；看取代基邻位是否有 H。
5. **黄酮/酚类与甲醛能缩聚**（酚 + 醛 → 酚醛树脂，需邻/对位有 H）。

## 三、错题逐条要点

| 题 | 关键点 | 我的原始答案 | 正确答案 |
|---|---|---|---|
| T01 | 硬脂酸饱和、油酸不饱和 | — | A |
| T02 | 🚩 **陷阱**：泛酸水解产物 D-泛酸（2,4-二羟基-3,3-二甲基丁酸）与乳酸 **β-羟基位置不同**，非"同系物"风格；分子式 C₉H₁₇NO₅ | — | B |
| T04 | 酯基 + 酚羟基 → 在强碱中会被破坏 | — | C |
| T10 | 黄酮碳全为 sp²；与 H₂ 加成数要算"苯环 3×2 + 双键 + 羰基" | — | D |

### T02 详拆（年级 93.6%，说明这是"人人都该会的简单题"）
- A：C₉H₁₇NO₅ —— 数碳 9 个（2+1+2+1+1+2），N1，O5 ✓
- B：泛酸酸性水解断酰胺键，得 **2,4-二羟基-3,3-二甲基丁酸**（C₆H₁₂O₄）。乳酸是 2-羟基丙酸（C₃H₆O₃）。二者**不是同系物**，因为羟基位置不同（一个含两个羟基 vs 一个羟基）。✗ **这就是"不正确"的选项**
- C：多羟基与水形成氢键 ✓
- D：乳酸 **两分子** 分子间酯化 → 交酯（六元环）✓

> 🚩 教训：**"互为同系物"要同时满足：结构相似（官能团种类、数目相同）+ 相差 n 个 CH₂。** 多一个羟基就不算了。

### T01 详拆
- A 油酸（C=C）× 褪色，硬脂酸（饱和）不褪 ✓ 可鉴别
- B 苯、环己烷 均不褪 ✗
- C 葡萄糖、麦芽糖 均含醛基，均褪 ✗
- D 丁烯醛（C=C + −CHO）、丁醛（−CHO）均褪 ✗

### T04 详拆
维生素 C（抗坏血酸）结构含 **烯二醇 + 内酯（环酯）**：
- A 官能团：羟基、**酯基（内酯）**、碳碳双键 ✓
- B 双键 + 烯二醇 → 溴水、KMnO₄ 都褪 ✓
- C **内酯在碱中水解开环**，强碱性环境不能保存 ✗
- D 有 σ、π ✓

### T10 详拆
- A：数出 C₁₅H₁₀O₅ 还是 C₁₅H₁₂O₅？—— 按结构清点，**分子式应为 C₁₆H₁₂O₅ 量级**，A 描述不精确
- B：黄酮骨架含 C=C，全部 sp² ✓
- C：苯环 3 个 → 6 H₂，C=C 1 个 → 1 H₂，C=O 1 个 → 1 H₂，共 8 H₂，非 7 ✗
- D：芳环 + 甲醛 → 酚醛缩聚（需邻/对位 H）✓ → **选 D**

## 四、一句话复盘

> 有机选择题的死法只有两种：**数不清**（H₂、NaOH 用量、分子式）和 **判不准**（官能团 → 反应）。
> 每题先写官能团清单，再逐项"能不能"。
