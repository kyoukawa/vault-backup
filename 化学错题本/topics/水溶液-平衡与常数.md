# 水溶液·平衡与常数

> 归入：「K / Ksp / 水解」「沉淀转化」「pH 与速率」
> 本主题错题：T25 T26 T28 T36（4 题，含 T26 50.0%）

## 一、三个常数的用法

| 常数 | 表达式 | 用来判断 |
|---|---|---|
| K（平衡常数） | 产物浓度幂/反应物浓度幂，**纯固体、纯液体不写** | 平衡移动、Q 与 K 比较 |
| Ksp | **饱和溶液中**离子浓度幂之积 | 谁先沉淀、能否转化、沉淀是否完全 |
| Ka/Kh/Kw | 弱酸电离、水解、水的电离 | pH、稀释、加热变化 |

### 沉淀完全 vs 开始沉淀
- **开始沉淀**：Q = Ksp
- **完全沉淀**（高中约定）：离子浓度 < **10⁻⁵ mol/L**

### Ksp 计算实例（T26 B 项）
Mg(OH)₂：Ksp = 5.6×10⁻¹²，pH = 11 → c(OH⁻) = 10⁻³
c(Mg²⁺) = 5.6×10⁻¹²/(10⁻³)² = **5.6×10⁻⁶ mol/L < 10⁻⁵** → **已沉淀完全** ✓

## 二、错题逐条

### T25 I₂ + I⁻ ⇌ I₃⁻（71.4%）→ 答案 B

已知 [I⁻] = [I₂] = 2.5×10⁻³，[I₃⁻] = 4.0×10⁻³

- A 加 CCl₄：I₂ 被萃取进有机层 → **水层 c(I₂) 降低** ✓
- **B** 加等体积水（稀释 2 倍，浓度先减半）：若不考虑平衡移动，c(I₂) = 1.25×10⁻³；
  但稀释使平衡 **I₂ + I⁻ ⇌ I₃⁻ 逆向移动**（相当于 Q 变小，向粒子数多的一侧）→ **实际 c(I₂) 略高于 1.25×10⁻³**，故"< 1.25×10⁻³" **✗ → 答案**
- C K = [I₃⁻]/([I⁻][I₂]) = 4.0×10⁻³ / (2.5×10⁻³ × 2.5×10⁻³) = 4.0×10⁻³ / 6.25×10⁻⁶ = **640** ✓
- D 加 KI：I⁻ 浓度增大 → 促进 I₂ 溶解（以 I₃⁻ 形式）✓

> 🚩 **稀释时"改变量"比"浓度减半"更多还是更少，取决于平衡移动方向**，这是选择题最爱考的。

### T26 粗盐水精制（50.0% ★）→ 答案 D

流程：粗盐水 --①BaCO₃--> --②NaOH--> --③过滤--> 滤液 --④调pH--> 精制盐水
已知 c(SO₄²⁻) > c(Ca²⁺)，Ksp：BaSO₄ 1.1e-10、BaCO₃ 2.6e-9、CaCO₃ 3.4e-9、Mg(OH)₂ 5.6e-12

- A ① **沉淀转化**：BaCO₃(s) + SO₄²⁻ ⇌ BaSO₄(s) + CO₃²⁻
  平衡常数 K = Ksp(BaCO₃)/Ksp(BaSO₄) ≈ 24 → 可发生 ✓
- B pH=11 时 c(Mg²⁺) ≈ 5.6×10⁻⁶ < 10⁻⁵ ✓（见上）
- C 滤渣：BaSO₄、CaCO₃、Mg(OH)₂，还有**未反应的 BaCO₃** ✓
- D **用稀盐酸调到"微酸性"会引入过量 H⁺，且实际工艺应调至中性或微碱性**；更关键的是：**调 pH 目的不是"除去 OH⁻、CO₃²⁻"而是中和过量 NaOH/Na₂CO₃ 并防止后续工艺引入 Cl⁻ 过多** —— 按答案，D 为不正确项 ✗

> 🚩 流程题的套路：**每一种除杂剂的加入顺序，都有"谁多余的怎么办"的答案**。
> 盐酸调 pH 一定"**少量、至中性**"，写"微酸性"就是准备再加一步除酸——多此一举。

### T28 氧化还原使 pH 增大（89.5%）→ 答案 A

- A 酸性 KMnO₄ + FeSO₄：MnO₄⁻ + 5Fe²⁺ + 8H⁺ = Mn²⁺ + 5Fe³⁺ + 4H₂O → **消耗 H⁺ → pH 增大** ✓
- B NaHSO₃ + Ba(OH)₂：2HSO₃⁻ + Ba²⁺ + 2OH⁻ = BaSO₃↓ + SO₃²⁻ + 2H₂O → **耗 OH⁻ → pH 减小**，且不是氧化还原 ✗
- C BaCl₂ 通 SO₂ 再通 O₂：2SO₂ + O₂ + 2Ba²⁺ + 2H₂O = 2BaSO₄↓ + 4H⁺ → **生成 H⁺ → pH 减小** ✗（虽是氧化还原）
- D NaCl 通 NH₃ 再通 CO₂：生成 NaHCO₃ 沉淀（侯氏/索氏制碱）→ 非氧化还原 ✗
- → **A**（同时满足"氧化还原"和"pH 增大"）

> 🚩 这类题必须**两边都核**：先筛氧化还原，再筛 pH 方向。

### T36 NaClO 漂白·升降温（68.4%）→ 答案 D

数据：25℃(①) t₁，45℃(②) t₂，65℃(③) t₃，25℃(④) t₄，且 **t₄ > t₁ > t₂ > t₃**
（褪色时间越短 = 漂白越快）

- A 褪色原理 ClO⁻ + H₂O ⇌ HClO + OH⁻，HClO 漂白 ✓
- B ①→③ 升温：**HClO 生成（水解）减少**但**与红纸条反应速率加快**；两者影响方向相反 —— 由 t₃ 最短可知**速率因素占主导**，所以"影响一致"应为正确描述（命题人视为对）
- C t₄ > t₁：③ 高温后降温回 25℃，**水解平衡逆向移动，c(HClO) 比最初少**，且可能存在不可逆变化（HClO 分解/歧化）→ 漂白变慢 ✓
- D **45℃ 直接降到 25℃，未经 65℃ 的历史** → t₄ 是"经历 65℃ 再降温"的产物，直接降到 25℃ 应更快（t < t₄）→ 题干说"小于 t₄"其实是**合理推断**，按答案 D 反被判错 → 说明命题人认为"小于"不成立（应为 t₄ 与 t₁ 比较）

> 🚩 此题"历史路径"是关键：**溶液的漂白能力带"记忆"**，同一温度下处于不同热历程的溶液表现不同。

## 三、一句话复盘

> 水溶液题的核心是 **"写式子 + 算常数 + 看方向"**。所有定性选项都能用这三步落成定量。
