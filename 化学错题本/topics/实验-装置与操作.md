# 实验·装置与操作

> 归入：「四图判正误」「制气装置选择」「洗气顺序」
> 本主题错题：T18 T19 T20 T35（4 题）

## 一、装置选择速查

| 反应物状态 | 装置 | 例 |
|---|---|---|
| 固 + 固，加热 | 大试管（管口略向下 / 略向上） | NH₄Cl+Ca(OH)₂、KClO₃、MnO₂ |
| 固（块）+ 液，不加热 | 启普发生器（或简易版） | Zn+稀H₂SO₄、CaCO₃+盐酸 |
| 固 + 液 / 液 + 液，加热 | 圆底烧瓶 + 分液漏斗 | MnO₂+浓盐酸、乙醇制乙烯 |

## 二、常见气体收集与尾气

| 气体 | 制备 | 收集 | 尾气/干燥 |
|---|---|---|---|
| Cl₂ | MnO₂ + 浓盐酸，**加热** | **向上排空气** | 饱和食盐水洗 HCl，浓硫酸干燥，NaOH 吸收 |
| SO₂ | Cu + **浓硫酸加热**（稀硫酸不反应！） | 向上排空气 | NaOH |
| NO | Cu + 稀硝酸 | **排水法**（会被空气氧化） | — |
| NH₃ | NH₄Cl + Ca(OH)₂ **加热** | **向下排空气** | 棉花防对流 |
| H₂ | Zn + 稀硫酸 | 排水 / 向下排空气 | — |
| CO₂ | CaCO₃ + 盐酸 | 向上排空气 | — |

### 洗气顺序铁律
**先除杂，后干燥**；除杂要用"不消耗主气体"的试剂。
- Cl₂：**先饱和食盐水（除 HCl），后浓硫酸（除水）** ← 反了就白干
- CO₂：先饱和 NaHCO₃，后浓硫酸

## 三、错题逐条

### T18 四图判正误（69.0%）

- **A 配 1.00 mol/L NaCl**：容量瓶定容时"液面离刻度线 1–2 cm 改用胶头滴管"✓ → 正确
- B 滴定管放液：**酸式滴定管（带玻璃活塞）不能用拇指顶住活塞转动，应"三指法"**（拇指+食指捏住拧，或左手），手直接握持易带出溶液、也易漏 ✓ 描述为错
- C 量取 **8.10 mL**：量筒只能读到 0.1 mL（10 mL 量筒），**8.10 是 0.01 精度** → 应用 25 mL 酸式滴定管或移液管 ✗
- D 制硫酸四氨合铜晶体：需在**硫酸铜溶液中滴加氨水至沉淀恰好溶解**，再**加入乙醇**析出，直接加热蒸发会分解 → 描述不严谨 ✗
- → **答案 A**

### T19 制氯气装置（88.5%）

- A 制 Cl₂ ✓（但气体走向应为 长进短出）
- **B 除杂：气流应先经饱和食盐水、再经浓硫酸；图中"长进短出/短进长出"接反了**（洗气瓶必须长管进气）✗ → 答案
- C 收集 Cl₂（密度大于空气，长进短出 / 向上排空气）✓
- D 用水吸收尾气 ✗（Cl₂ 微溶，应用 NaOH）

### T20 制气四联表（93.1%）

| | 气体 | 试剂 | 装置 | 收集 | 判断 |
|---|---|---|---|---|---|
| A | Cl₂ | MnO₂+浓盐酸 | b | e | b 是固液加热，**图 b 无加热装置** → 至少"装置"待商榷，但常识上这是标准组合 |
| B | SO₂ | Cu+**稀硫酸** | b | c | ❌ Cu 与稀硫酸**不反应** |
| C | NO | Cu+稀硝酸 | b | c | 装置 ✓，收集应为**排水 c** ✓ |
| D | NH₃ | NH₄Cl+Ca(OH)₂ | a | d | a 固固加热 ✓，d 向下排空气 ✓ → **全对** |

→ **答案 D**

> 🚩 高频陷阱：**Cu + 稀硫酸不反应**；**NO 不能用排空气法**；**Cl₂ 不能用排水**。

### T35 Na₂S₂O₃ 制备（84.2%）

- A 先变浑浊：2Na₂S + 3SO₂ = 2Na₂SO₃ + 3S↓ ✓
- B Na₂CO₃ 吸 SO₂ 兼调 pH：SO₂ + Na₂CO₃ = Na₂SO₃ + CO₂ ✓
- C 加乙醇降低 S 的溶解 → 说法"增大 S 溶解度" ✗？——命题人视为正确项（乙醇加快反应、利于 S 分散），存疑
- D **通入过量 SO₂**：SO₂ 会把已生成的 Na₂S₂O₃ 进一步酸化 → 变成 NaHSO₃ + S 或 SO₂ 溶解，**产率下降** ✗ → 答案 **D**

> 🚩 记一个规律：**制备易被酸分解的含氧酸盐（S₂O₃²⁻、NO₂⁻），一定"少量"酸性气体**。

## 四、一句话复盘

> 实验选择题八个高频考点：**长进短出 / 先除杂后干燥 / 加热与否 / 排水还是排空气 / 精度（量筒 0.1、滴定管 0.01）/ 尾气处理 / 防倒吸 / 蒸发 vs 冷却结晶**。
