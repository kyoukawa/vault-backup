# 速查 · 沉淀溶解平衡表

> 配套：[[topics/水溶液-平衡与常数]]、[[topics/电化学-电极与方向]]、[[topics/离子方程与化学用语]]
> 用途：Ksp 相关选择题（谁先沉淀 / 能否转化 / 是否完全 / 电极式带不带沉淀）一张纸查完。

## 一、公式区（四行背完）

| 判断 | 判据 | 备注 |
|---|---|---|
| 有无沉淀 | **Q 与 Ksp 比**：Q>Ksp 沉淀，Q=Ksp 饱和，Q<Ksp 不沉淀 | Q 与 Ksp 必须**同型**才能直接比 |
| 开始沉淀 | 加沉淀剂到 **Q = Ksp** 的那个浓度 | 求"某离子开始沉淀时另一离子浓度" |
| 沉淀完全 | 高中约定残余离子 **< 10⁻⁵ mol/L** | 求"沉淀完全时 pH"必用 10⁻⁵ |
| 沉淀转化 A→B | **K = Ksp(A) / Ksp(B)** | K 很大→自发；见第三节 |

**同型才能直比**：AgCl 与 AgBr 同为 AB 型，Ksp 小者先沉淀；AgCl(AB) 与 Ag₂CrO₄(A₂B) **不能**直接比 Ksp（数值小反而后沉淀，见第四节）。

## 二、溶解度换算（把 Ksp 翻译成"多少 mol/L"）

| 类型 | 例 | 溶解度 s 与 Ksp |
|---|---|---|
| AB（1:1） | AgCl、BaSO₄、CaCO₃ | Ksp = s² → s = √Ksp |
| AB₂ / A₂B（1:2） | Mg(OH)₂、CaF₂、Ag₂CrO₄ | Ksp = 4s³ → s = ∛(Ksp/4) |
| AB₃（1:3） | Fe(OH)₃、Al(OH)₃ | Ksp = 27s⁴ → s = ⁴√(Ksp/27) |

> 🚩 **只有同类型**才"Ksp 越小越难溶"。跨类型一律换算成 s 再比。

**高频心算（记结论，不记推导）**

| 沉淀 | 近似 Ksp(25℃) | 饱和溶液 c(金属离子) |
|---|---|---|
| Mg(OH)₂ | 5.6×10⁻¹² | s ≈ 1.1×10⁻⁴ |
| Fe(OH)₂ | 8×10⁻¹⁶ | s ≈ 6×10⁻⁶ |
| Fe(OH)₃ | 4×10⁻³⁸ | s ≈ 2×10⁻¹⁰（极难溶） |
| Al(OH)₃ | 1×10⁻³³ | s ≈ 5×10⁻⁹ |
| BaSO₄ | 1.1×10⁻¹⁰ | s ≈ 1×10⁻⁵ |
| BaCO₃ | 2.6×10⁻⁹ | s ≈ 5×10⁻⁵ |
| CaCO₃ | 3.4×10⁻⁹ | s ≈ 6×10⁻⁵ |
| AgCl | 1.8×10⁻¹⁰ | s ≈ 1.3×10⁻⁵ |

> 数值以题给为准，上表只用于估方向和量级。**考试时一律用题干给的 Ksp。**

## 三、沉淀转化方向（K = 前 / 后）

反应：`A(s) + 离子 ⇌ B(s) + 离子'`

```
K = Ksp(被溶解的那个) / Ksp(新生成的那个)
```

| 转化 | K | 判断 |
|---|---|---|
| BaSO₄ → BaCO₃ | 1.1e-10 / 2.6e-9 ≈ **0.04** | 难 → 需高浓度 CO₃²⁻，反复多次 |
| BaCO₃ → BaSO₄ | ≈ **24** | 易（T26 的 A 项就是它） |
| AgCl → AgBr → AgI → Ag₂S | 依次 **Ksp 更小** | 一路易走，反向极难 |
| AgCl → AgI | Ksp(AgCl)/Ksp(AgI) ≈ 10⁶ | 极易 |

**两条判据**
1. **K 大（>1 且量级够）→ 自发**；K 很小不一定不发生，靠**提高浓度**硬推（如 BaSO₄ 加饱和 Na₂CO₃ **反复多次**）。
2. 沉淀转化后，**原沉淀的离子回到溶液**——流程题"滤液里多了什么"就看这一步。

## 四、同离子效应 & 跨类型反直觉

- **同离子效应**：加入含同名离子（过量沉淀剂）→ 溶解度**变小**，沉淀更完全。
  - 例：BaSO₄ 在 0.1 mol/L Na₂SO₄ 中，c(Ba²⁺) = Ksp/0.1 ≈ 1.1×10⁻⁹。
- **过量沉淀剂的另一面**：AgCl 加过量 **氨水** → 生成 [Ag(NH₃)₂]⁺ 而**溶解**（络合，不是同离子效应）。
- **跨类型"谁先沉淀"（经典坑）**：Cl⁻ 与 CrO₄²⁻ 混合液滴 AgNO₃，
  Ksp(AgCl)=1.8×10⁻¹⁰，Ksp(Ag₂CrO₄)=1.1×10⁻¹²。

  | 离子浓度 | 先沉淀所需 c(Ag⁺) | 算式依据 |
  |---|---|---|
  | 0.1 M Cl⁻（AgCl，AB 型） | 1.8×10⁻⁹ | c(Ag⁺)·c(Cl⁻)=Ksp |
  | 0.1 M CrO₄²⁻（Ag₂CrO₄，A₂B 型） | 1.1×10⁻⁵·⁵ ≈ 3.3×10⁻⁶ | **c²(Ag⁺)·c(CrO₄²⁻)=Ksp** |

  > ⚠️ **务必按化学式写对指数**：Ag₂CrO₄ 的 c(Ag⁺) 是**平方**。Ksp 数值小 ≠ 先沉淀，全看指数。
- **难溶 ≠ 不溶**：AgCl Ksp 很小，但要 c(Ag⁺)·c(Cl⁻) > Ksp 才沉淀。

## 五、Ksp 与电极式（来自 [[topics/电化学-电极与方向]]）

> **凡题干给出 Ksp 或 pH，电极式极可能要写成"生成沉淀/难溶物"的形式。**

| 题干线索 | 电极式写法 |
|---|---|
| 海水/碱性介质 + Zn | Zn − 2e⁻ + 2OH⁻ = **Zn(OH)₂**（不是 Zn²⁺） |
| 碱性介质 + Fe、Ni、Co | M − 2e⁻ + 2OH⁻ = **M(OH)₂** |
| 弱酸根存在的溶液 | 产物写成**难溶盐**而非自由离子 |
| 生成 AgCl 的参比/测量极 | Ag − e⁻ + Cl⁻ = **AgCl(s)** |

**验算逻辑（T13 那题）**：Ksp[Zn(OH)₂]=3×10⁻¹⁷，pH=8.5 → c(OH⁻)=10⁻⁵·⁵
→ c(Zn²⁺) ≤ 3×10⁻¹⁷/(10⁻⁵·⁵)² ≈ 3×10⁻⁶ ≪ 1 → **溶液里不可能以 Zn²⁺ 存在** → 必写沉淀式。

## 六、沉淀完全 → 求 pH（滴定/除杂题必考）

对 M(OH)ₙ：`c(Mⁿ⁺) = Ksp / c(OH⁻)ⁿ`

反解：沉淀完全时 c(Mⁿ⁺)=10⁻⁵ → `c(OH⁻) = (Ksp/10⁻⁵)^(1/n)` → pOH → pH

| 例子 | 算式 | 结果 |
|---|---|---|
| Mg²⁺ 沉淀完全 | c(OH⁻)=√(5.6e-12/1e-5)≈7.5×10⁻⁴ | pOH≈3.1，**pH≈10.9** |
| Fe³⁺ 沉淀完全 | c(OH⁻)=∛(4e-38/1e-5)≈1.6×10⁻¹¹ | pOH≈10.8，**pH≈3.2** |
| 分离 Fe³⁺/Mg²⁺ | 调 pH 在 3.2~10.9 之间 | **pH≈4 即可** |

> 🚩 除杂流程的"控制 pH 范围"题：**下限 = 杂质离子沉淀完全，上限 = 目标离子开始沉淀**。

## 七、流程图除杂顺序（T26 模板）

粗盐水 --①BaCl₂/BaCO₃--> --②NaOH--> --③过滤--> --④调 pH--> 精制盐水

| 问题 | 答法 |
|---|---|
| ①为什么先加 | 先除 SO₄²⁻，多余 Ba²⁺ 由后面 CO₃²⁻ 除掉 |
| 滤渣有几种 | BaSO₄、CaCO₃、Mg(OH)₂，**还要加未反应的 BaCO₃** |
| ④调 pH 用什么 | 稀盐酸，**少量、至中性（不是微酸性）** |
| "微酸性"为何错 | 多引入 H⁺，后续还需再处理，工艺上多此一举 |

## 八、常见错法清单

1. 跨类型直接比 Ksp（Ag₂CrO₄ vs AgCl）→ 换算 s，或按化学式指数算所需离子浓度。
2. 沉淀转化 K 写反（写成"新/旧"）→ **K = Ksp(被溶解)/Ksp(新生成)**。
3. 忘了同离子效应，用纯水中的溶解度作答。
4. 沉淀完全临界值：题给就按题给，未给时按 **10⁻⁵**（部分教材写 10⁻⁶）。
5. 电极式里把本该成沉淀的离子写成自由离子（见第五节）。
6. 流程题忘了"未反应的过量试剂也在滤渣里"。
