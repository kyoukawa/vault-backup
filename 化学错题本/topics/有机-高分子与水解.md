# 有机·高分子与水解

> 归入：「缩聚 / 加聚」「能水解什么、水解几个」「糖类·核酸·氨基酸·油脂」
> 本主题错题：T03 T05 T07 T09（4 题，含年级最低的 T07 38.2%）

## 一、一套模板判断聚合反应

| 问 | 判据 |
|---|---|
| 是加聚还是缩聚？ | 单体里有 **−OH/−COOH/−NH₂** 两两脱水 → 缩聚；只有 C=C/C≡C 打开 → 加聚 |
| 有小分子生成吗？ | 缩聚**必**脱 H₂O（或 HCl、NH₃）；加聚 **不**脱 |
| 原子利用率 100%？ | 只有**加聚**和**加成**能做到 |
| 官能团几种？ | 逐个数重复单元里的独立官能团，**重复单元 ≠ 一种官能团** |
| 1 mol 高聚物水解消耗多少 NaOH？ | 找到**每个重复单元**中的酯/酰胺/酚羟基，再乘 n |

## 二、糖类·油脂·核酸·蛋白质（选择题必背表）

| 物质 | 是否同分异构 | 醛基 | 水解产物 |
|---|---|---|---|
| 蔗糖 C₁₂H₂₂O₁₁ | 与麦芽糖**互为**同分异构 | ❌ 无还原性 | 葡萄糖 + 果糖 |
| 麦芽糖 C₁₂H₂₂O₁₁ | 同上 | ✅ 有还原性 | 2 葡萄糖 |
| 淀粉/纤维素 | (C₆H₁₀O₅)ₙ | ❌ | 葡萄糖（最终） |
| 油脂 | — | — | **酸性**水解：甘油 + 高级脂肪酸；**碱性**水解才叫皂化 |

> 🚩 **"蔗糖和麦芽糖…均能发生银镜反应"→ 错**。蔗糖是非还原糖。
> 🚩 **"油脂酸性水解…又称皂化反应"→ 错**。皂化专指碱性水解。

### 两个氨基酸混合能生成几种二肽？

- 两种不同氨基酸（A、B）：**A-A、A-B、B-A、B-B = 4 种**（顺序不同是不同物质）
- 若只说"生成二肽"不限顺序、不考虑自缩合 → **2 种（AB、BA）**
- 题干写"最多生成**两种**"→ 少算了同种缩合（AA、BB），✗

### 核酸

- 脱氧核糖核苷酸 → 通过 **磷酸二酯键** 聚合 → DNA 单链
- 🚩 原题写"通过**磷酸键**缩合"——**术语不严谨，通常是错项**

## 三、错题逐条

### T07 PPC（38.2% ★最难）—— 一定要过一遍

PPC = 环氧丙烷 + CO₂ + 顺丁烯二酸酐 三元共聚（**加聚，无小分子生成**）
重复单元：

```
   CH₃           O
   |             ||
-[CH₂-CH-O-C-]ₙ -[CH=CH-C-O]ₘ-    →接在链上形成 酯基（-COO-）+ 双键
```

- A **"PPC 中含 2 种官能团"**：重复单元里其实只有 **酯基**一种（碳酸酯基和羧酸酯基在高中通常都算"酯基"；若严格分，是"碳酸酯基 + 酯基 + 碳碳双键"）。命题人的意思：**明确写出的官能团应把碳碳双键也算进去 → 至少有酯基和碳碳双键两种，但若把碳酸酯与羧酸酯分开则为 3 种 → A 说法不准确** ✗ ← 是"不正确"的答案
- B 加聚过程无小分子 ✓
- C 顺丁烯二酸酐有 C=C，使 Br₂/CCl₄ 褪色 ✓
- D 有双键可交联改性 ✓

> 🚩 教训：**"中含有 X 种官能团" 的题，一定把重复单元拆开数全**——酯基、醚键、双键、羟基、酰胺，一个都不能漏。

### T03 PCT（78.6%）

PCT = 对苯二甲酸 X（HOOC–C₆H₄–COOH）+ 1,4-环己烷二甲醇 Y（HOCH₂–C₆H₁₀–CH₂OH）缩聚。

- A **"X 可与 H₂ 加成生成 Y"**：X 苯环加氢变成 **环己烷二羧酸**（—COOH 不还原），不是二甲醇 ✗ ← 答案
- B Y 对称性高：环己烷上 4 种 H（1、2、3、4 位），plus CH₂ = 4 组峰 → 说法为"有 4 组" ✓（按命题设定）
- C 缩聚 ✓
- D 有酯基 → 碱性中水解 ✓

### T05 PLA（77.4%）

乳酸 →（脱水成丙交酯"中间体"）→ 开环聚合成高分子量 PLA。

- A PLA 有大量酯基、疏水，**难溶于水** ✗
- B **中间体**由**两分子乳酸**脱水生成丙交酯，同时脱去 **2 分子 H₂O**，原子利用率 **< 100%** ✗
- C 乳酸直接脱水缩聚 → 低分子量 PLA，属缩聚 ✓ ← 答案
- D 每个重复单元 −O–CH(CH₃)–CO– 有 1 个酯基 → **1 mol PLA（以重复单元计）消耗 1 mol NaOH** ✓ 但题问"1 mol PLA"，若按整条高分子算则远大于 1；命题人以"1 mol PLA 完全水解消耗 1 mol NaOH"为错误（高分子无固定摩尔质量） → 与 C 相比 C 更对，答案 C

> 🚩 归纳：**高聚物没有"1 mol 消耗几个"这种问法能成立的绝对答案**，一旦出现就要警惕（应为"1 mol 重复单元"）。

### T09 四合一（89.7%）

- A 蔗糖无醛基 ✗（同分异构那句对，银镜那句错）
- B "磷酸键缩合"→ 应为**磷酸二酯键** ✗
- C 两种氨基酸最多 **4** 种二肽，不是 2 种 ✗
- D 酸性水解不叫皂化 ✗
- 答案 **B**（命题人认定脱氧核糖核苷酸聚合的描述为正确项——注意：**这题四个说法都有瑕疵，属原题质量问题**，年级 89.7% 说明大部分人还是按"排除最错的"选了 B）

## 四、一句话复盘

> 高聚物的四连问：**怎么聚的 → 脱不脱水 → 官能团几个 → 水解耗多少碱**。
