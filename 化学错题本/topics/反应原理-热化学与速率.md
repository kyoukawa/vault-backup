# 反应原理·热化学与速率

> 归入：「盖斯定律」「ΔH 与条件」「速率与转化率」
> 本主题错题：T37（原卷理12，年级 96.4%，属"不该错"）

## 一、盖斯定律三步法

1. 写出**目标方程式**（先写，别急着算）
2. 把已知方程式变形（×系数 / 反向）拼成目标式
3. **ΔH 同步做同样的运算**

常用技巧：
- 目标式中某物质在**右边** → 找它在右边的已知式直接加，在左边的就**反写**（ΔH 变号）
- 系数用分数，不要急着通分

## 二、错题 T37（96.4% ★不该错）

已知：
- ① CO(g) + 2H₂(g) ⇌ CH₃OH(g)　ΔH₁ = −90.5 kJ·mol⁻¹
- ② CO(g) + H₂O(g) ⇌ CO₂(g) + H₂(g)　ΔH₂ = −41.1 kJ·mol⁻¹
- ③ 2H₂(g) + O₂(g) = 2H₂O(g)　ΔH₃ = −483.6 kJ·mol⁻¹

**求：CO₂(g) + 3H₂(g) ⇌ CH₃OH(g) + H₂O(g) 的 ΔH**

推导：
- 目标 = ① **−** ②
- ① − ②：CO + 2H₂ − (CO + H₂O) ⇌ CH₃OH − (CO₂ + H₂)
  → −H₂O ⇌ CH₃OH − CO₂ − H₂
  → CO₂ + 3H₂ ⇌ CH₃OH + H₂O ✓
- **ΔH = (−90.5) − (−41.1) = −49.4 kJ·mol⁻¹**

逐项：
- A **"反应①中生成 1 mol CH₃OH(l) 时放出的热量大于 90.5 kJ"**：① 给的是 **气态 CH₃OH(g)**；气→液**放热**，所以生成液态时放热更多 ✓ **正确**
- B 方程式与 ΔH = −49.4 ✓ **正确**
- C **"通过电解制 H₂ 和选用高效催化剂，可降低 CO₂ 与 H₂ 合成甲醇反应的焓变"**：**催化剂只改变活化能，不改变 ΔH** ✗ ← **答案**
- D 以 CO₂ + H₂O 制甲醇同时生成 O₂：
  目标 ④：CO₂ + 2H₂O → CH₃OH + 3/2 O₂
  = ① − ② − ③/2 → ΔH = −90.5 + 41.1 + 241.8 = **+192.4 kJ·mol⁻¹ > 0，吸热** ✓ **正确**
- → **答案 C**

> 🚩 **最高频的送分陷阱：催化剂不改 ΔH。** 卷面年级得分率 96.4%，几乎人人都该会 —— 这题错了说明**审选项时太快**。

## 三、热化学五条铁律

1. **ΔH 与化学计量数成正比**；方程式系数减半，ΔH 也减半
2. **ΔH 带符号**：放热为负，吸热为正；**"放出 90.5 kJ" 对应 ΔH = −90.5**
3. **注明物质状态**；同一物质气/液/固的 ΔH 不同
4. **可逆反应不能算"完全转化"**：题干说"生成 1 mol"时要看是否标注"理论"或"实际"
5. **催化剂/压强/温度**：只有**温度**改 ΔH 的测定值（严格说改平衡常数），催化剂只改速率

## 四、一句话复盘

> 热化学题只有两类：**盖斯定律算数**（细心）和 **ΔH 概念辨析**（催化剂/状态/计量数）。
> 后者才是真正的失分点。
