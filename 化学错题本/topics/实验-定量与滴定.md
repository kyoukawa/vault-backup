# 实验·定量与滴定

> 归入：「测某物质量分数的方案是否可行」「滴定中的异常现象」「误差方向」
> 本主题错题：T21 T22（2 题，都是年级低分区：55.6% / 38.9%）

## 一、判断"方案是否可行"的三连问

1. **反应是否完全、是否只有一个产物来源**？（有没有副反应、平行反应）
2. **测量量是否只由"待测量"决定**？（b g 里有没有混进别的组分的贡献）
3. **能不能反推唯一的未知数**？（一个方程一个未知数）

## 二、错题 T22 Na₂O₂ 质量分数（38.9% ★）

背景：Na₂O₂ 与呼出气体（CO₂、H₂O）反应后剩余 **Na₂O₂ 与 Na₂CO₃ 的混合物**（也可能含 NaOH），测其中 Na₂O₂ 的质量分数。

| 方案 | 分析 | 判定 |
|---|---|---|
| A 足量水，收集标准状况下 **b L 干燥气体** | 只有 Na₂O₂ 与水放 O₂：2Na₂O₂ + 2H₂O = 4NaOH + O₂↑，**Na₂CO₃ 不产气** → n(Na₂O₂) = 2×b/22.4 | ✅ 可行 |
| B 足量稀硫酸，逸出气体用碱石灰吸收增重 b g | 逸出的 **CO₂** 来自 Na₂CO₃（Na₂O₂ 与酸放 O₂ 不被碱石灰吸收，但**水蒸气也会被吸收**，且 O₂ 带出水分）→ 增重 b g = CO₂ + H₂O，无法分离 | ❌ 不可行 |
| C 足量 BaCl₂，沉淀质量 b g | 只有 Na₂CO₃ → BaCO₃，但混合物里可能还有 **NaOH**，NaOH 不沉淀，无法求 Na₂O₂ 的量 | ❌ |
| D 足量盐酸，蒸干灼烧得 b g 固体 | 全部变成 **NaCl**，只能得总钠量，不能区分两者 | ❌ |
| → **答案 A** | | |

> 🚩 通用心法：**"收集气体体积"往往最干净**，因为气体可以做到只来源于一种物质；
> "称沉淀/称固体"则容易被第三种组分污染。

## 三、错题 T21 海带碘含量（55.6% ★）

流程：10.00 mL 含 I⁻ 待测液 + 过量 H₂O₂ + H₂SO₄（淀粉指示剂）→ **蓝色（I₂ 生成）**
→ 用 0.0082 mol/L Na₂S₂O₃ 滴定 → 蓝色褪去 → **又变蓝** → 继续滴定（耗 V₂ mL）→…

关键反应：**H₂O₂ + 2I⁻ + 2H⁺ = I₂ + 2H₂O**（题目 A 项就是这么写的）
滴定：I₂ + 2S₂O₃²⁻ = 2I⁻ + S₄O₆²⁻

**为什么会"反复变蓝"？**
因为 H₂O₂ **过量且仍在缓慢氧化 I⁻**，而 S₂O₃²⁻ 消耗 I₂ 更快；两者速率竞争：
- 若 H₂O₂ 氧化 I⁻ 的速率 **> Na₂S₂O₃ 还原 I₂ 的速率** → 滴完又补 I₂ → 变蓝
- → 选项 C 的描述是**正确**的（这正是反复变蓝的根本原因）

逐项：
- A 蓝色源于 H₂O₂ + 2I⁻ + 2H⁺ = I₂ + 2H₂O ✓
- B 密闭/敞口都复蓝 → 说明与空气中 O₂ 无关 ✓
- C 速率竞争解释 ✓
- D **"加入少量 MnO₂ 分解残余 H₂O₂，过滤后再滴定"**：MnO₂ 会**催化分解 H₂O₂**，正确；但题目说"上述实验不能准确测定"——事实上多次滴定累加 V₁+V₂+… 同样可以定量（只是要等多到不再变蓝）。
  **命题人认为 D 是"不正确"的那项**——按答案 D，其意思应为：反复变蓝不是 H₂O₂ 残余的问题，加 MnO₂ 后反而会**引入 Mn²⁺/MnO₂ 氧化 I⁻ 的新干扰**，或"不能被 MnO₂ 有效除去"。

> 🚩 本题年级 55.6%，是"信息量大、四个说法都要推"的综合题。
> **做这类题的顺序：先把每个反应式写全（包括滴定反应），再逐个选项回题干找证据。**

## 四、滴定误差方向速查

| 操作失误 | c(待测) |
|---|---|
| 滴定管未润洗 | 偏高 |
| 用待测液润洗锥形瓶 | 偏高 |
| 滴定前有气泡，滴定后消失 | 偏高 |
| 读数：俯视初、仰视末 | 偏高 |
| 指示剂变色后立即读数（未等 30 s） | 偏低 |
| 待测液在烧杯中未全部转移 | 偏低 |

## 五、一句话复盘

> 定量实验就两件事：**测量量只对一种物质敏感**，和 **误差方向能一句说清**。
