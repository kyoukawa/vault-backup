# 阅表题写作思路 2026.11.24

> 适用：英语阅表 / 图表数据 / 读后续写价值升华类
> 来源：课堂版书「五种价值转换角度」（2026-11-24 照片抄录）
> 定位：**题型方法论**，与 [[00-跨主题句式库]] 的 8 条万能句式配合用

---

## 一、五种价值转换角度（原表逐字保留）

| 角度 | 引导问题 | 表达参考 |
|---|---|---|
| 心理层面 | 这样做让作者获得什么? | `find inner peace` / `reduce anxiety` / `regain confidence` |
| 认知层面 | 作者改变了什么认识? | `gain a new perspective` / `understand himself better` |
| 行动层面 | 他没有因此放弃什么? | `keep participating` / `continue communicating` |
| 成长层面 | 他从经历中获得什么? | `grow through difficulties` / `turn a burden into an opportunity` |
| 人生层面 | 这体现了什么道理? | `limitations do not define us` / `focus on what we can control` |

---

## 二、核心用法：五层是「筛选器」，不是「全写」

**最大误区**：把五层当清单逐条写 → 变成五个句子拼盘，没有推进感。

**正确用法**：五层是**选二层**，且必须**跨层递进**，不能停在同一层。

### 1. 先定位材料给的是哪一层

读表题/数据题通常只给「事实层」。你要做的是**往上找一层**：

| 材料给的是 | 该往哪升 |
|---|---|
| 数据 / 比例 | 认知层（人们改变了什么看法） |
| 现象 / 行为 | 心理层（背后是什么需求/情绪） |
| 事件 / 经历 | 成长层（从中学到什么） |
| 个人故事 | 人生层（体现什么普遍道理） |

### 2. 选一条主轴，跨两层收束（三种最稳走法，选一别混）

| 组合 | 走向 | 适合材料 |
|---|---|---|
| 心理 → 成长 | `find inner peace` → `turn a burden into an opportunity` | 压力 / 挫折 / 挑战 |
| 认知 → 人生 | `gain a new perspective` → `limitations do not define us` | 观念转变 / 偏见 / 包容 |
| 行动 → 成长 | `keep participating` → `grow through difficulties` | 坚持 / 参与 / 公益 |

### 3. 每层配一个具体细节当支点

升华句前必须有**具体画面或数字**，否则层级是空的。（对应 [[00-跨主题句式库]] 避坑：先给具体画面/动作，再升华。）

---

## 三、可直接套的骨架

```
现象 / 数据（一句）→ 背后的需求或认知变化（认知层）
→ 具体一个人 / 一件事（细节支点）
→ 这让人（成长层 / 人生层）……
```

**铁律**：`limitations do not define us` 这类人生层句子**只作收尾一句**，不能当分论点展开——一展开就假大空，是阅表题最常见的降分点。

---

## 四、考场调用（怎么跟万能句式接）

1. 题目给了图表/数据 → 先写「事实层」一句（引用具体数字，不写死数据，写趋势/比例）
2. 用五层里的某一层接住 → 挑一个能落到具体人身上的角度
3. 收尾用人生层一句 → 必须是一个**普适道理**，回到人本身
