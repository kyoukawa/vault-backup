刚刚，OpenAI 发布了 ChatGPT Wallet。

ChatGPT Wallet

一句话介绍，就是你的 dot 现在可以替你花钱了。

dot 是 OpenAI 9 月底推出的全天候 Personal Agent，有自己的云电脑，能连 4000 多款应用，平时帮你跟进项目、写代码、改方案。

而这一次，它终于拿到了一个钱包。

当然，钱包里并没有你的真卡号。按官方的说法，dot 只有在你批准之后才能替你下单，Agent 付款时拿不到你真实的卡号，每一笔购买都要过一道安全验证。

OpenAI 称它是第一个让 Agent 付款却接触不到真实卡号、且每笔都要验证的钱包，由 American Express、Mastercard 和 Visa 三家一起合作打造。

从今天开始，美国的 ChatGPT Pro 用户可以在 dot 里陆续用上。

给朋友挑礼物

01

OpenAI 放出了一段 45 秒的演示，演示里用户的 dot 叫 Rufus。

用户想在节前给朋友 Amelia 挑份礼物，便跟它说 Amelia 喜欢做饭、做陶艺，还爱养植物，预算 100 美元左右。

下需求、挑礼物

Rufus 先答应会找一份 100 美元左右、能把她这几个爱好串起来的礼物，而且不去猜她已经有哪些陶艺工具了。

然后它挑中了一盒 Guest & Ribbon 的厨房香草礼盒，税前 59.97 美元，有货、美国境内包邮。盒子里有罗勒、鼠尾草、百里香等五种香草，可以先在盒子里种，以后再移到她自己做的陶盆里。

它还顺带出了个主意，让你再塞一张手写的、用到其中一种香草的菜谱，这样礼物更像是你亲手准备的，还不用把 100 美元花满。

用户回了句「好主意！就这么办」，Rufus 又问要不要先寄到你这儿，好让你把菜谱塞进去。用户说 Yes。

接下来，就到了付钱这一步。

刷脸确认付款

Rufus 先用已保存的收货信息核算了最终总价，然后发来一个确认弹窗，总价 66.30 美元，收款方是 Guest & Ribbon，商品、送达日期（11 月 24 日）、收货地址和要扣款的 Visa 信用卡等信息都会列在上面，一目了然。

你只需点 Approve，Face ID 一扫，过了。

下单完成

几秒钟后，Rufus 便会汇报说已经下好单了，66.30 美元扣在尾号 4242 的 Visa 上（搞过支付的朋友估计会心一笑……这正是 Stripe 测试卡的经典卡号）。

标准快递寄往西雅图，11 月 24 日送达，还附上了订单号。

最后它还特意提醒，回执上的卡号后四位可能会和你的卡对不上，因为它用的是一张虚拟卡，为的是保护你的卡片信息。

从提需求到付完款，用户自己真正动手的，就只有一句「好主意」、一个 Yes 和一次刷脸……

以后剁手，都不用自己来了。

支付方案

02

那 Agent 到底是怎么付的钱呢？

用户只需要先在 Wallet 里绑一次卡，之后每笔购买点一下批准就行，不用再重新输卡号。

每次付款前，用户会看到商品、总价和要用的卡，然后用 Face ID 或指纹之类的安全验证来批准。每一次批准，都会留下一条清楚的授权记录，记着你允许 Agent 买了什么。

确认付款弹窗

批准之后，卡组织会生成一个支付令牌（payment token），它代替你真实的卡片信息，自带一套卡号、安全码和有效期。

真卡锁家里，替身卡出门

钱最终还是从你选的那张卡上扣，但你真实的卡号，商家看不到，Agent 也看不到。

演示里的回执尾号会对不上，原因正在于此。

用的是虚拟卡

而用户原来那张卡的积分、返现等权益都还在，遇到商品有缺陷这类符合条件的纠纷，卡片原有的争议保护也照样有效。

交易的风险评估，交给银行和卡组织来做。

用户是直接和商家交易的，商家自己保留客户关系，价格、发货、退货和客服也都还是商家说了算。

OpenAI 还提到了下一步的打算，以后用户可以给 Agent 设好规则，比如消费上限、购买类目、时间段，提前批准这类购买，让 Agent 全权代买。当然，这会在现在的生物识别和授权记录之上，再加一层更强的保护。

先划好圈，再放手

到那时候，大概连那一下刷脸都可以省了……

三大卡组织

03

为这次发布站台的合作方是 American Express、Mastercard 和 Visa 三家。

对 Amex 来说，ChatGPT Wallet 是它「Agentic Commerce Experiences」的第一个落地集成，符合条件的 Amex 持卡人可以用自己的卡，每笔都由自己审核批准。

Mastercard 全球数字商业化负责人 Sherri Haymond 表示：

“

Agent 代替用户购物，应该加强、而不是绕过支付体系里已经建立起来的信任。

Visa 也表示，会把自己的基础设施接进来，把用户批准过的购买和商家已经在用的系统连起来。

商家接入

04

光有钱包还不够，商家得收得了这笔钱。

OpenAI 承认，Agent 购物还处在很早期，不少网站可能会无意中把 ChatGPT Wallet 或其他 Agent 支付的订单给拦掉，风控系统也可能把 Agent 发起的正常购买当成可疑交易，直接拒绝交易或取消订单。

亮出签名，才不被当爬虫

所以 OpenAI 同时还发布了一份 Commerce Partner Playbook，教商家怎么接待用 Agent 来购物的顾客，主要是下面四件事。

1.  在 ChatGPT 里认领商家，上传带实时价格和库存的商品数据

2.  在 CDN 或防火墙上识别 Web Bot Auth 签名的请求，别把 ChatGPT 的 Agent 当爬虫给拦了

3.  找支付和风控服务商，让他们能认出 Agent 的正常购买

4.  做一个插件，或给网站加上 WebMCP 工具，让 Agent 能直接查库存、管理购物车

其中第三件事，OpenAI 已经拉上了 Forter、Riskified、Sardine、Signifyd 这几家反欺诈公司，以及 Adyen、Checkout.com、Stripe 这些支付服务商合作。

OpenAI 还提到，ChatGPT 每周有 12 亿人在用，很多人本来就会用它查商品、比价、决定买什么，只是挑完之后，还得自己去下单付钱。

而现在，它想把最后付钱这一步也接管过来。

小范围开放

05

ChatGPT Wallet 从今天开始在 dot 里陆续上线，首批只开放给美国、年满 18 岁、持有符合条件的美国发行银行卡的 ChatGPT Pro 用户。

OpenAI 说先小范围放出来，是想从真实使用里学习，再和商家、银行、卡组织一起把兼容性和稳定性做好，之后再慢慢扩大。

如果你有美区 Pro 账号，有美国的卡了，那你可以去尝尝鲜了！
