@陈之琰
上周在[Personal Agent](https://mp.weixin.qq.com/s?__biz=MzYzNTA3NTgwNQ==&mid=2247484563&idx=1&sn=a9541b19883488f32080a4e988de46f8&scene=21#wechat_redirect)的留言里，很多读者反复提到：“人民需要 Personal Agent 吗？”
的确，这一轮AI应用的产品几乎都在服务所谓知识工作者：写代码的、做 ppt 的、做研究的、排日程的。在 Personal Agent 概念被单独拎出来之前，就普通人的AI产品而言，大家的第一反应还是豆包。
今年下半年，我注意到一个叫 Twoo 的AI应用，有些像 Personal Agent ，但也有不太一样的地方，是个很难三言两语说清楚的产品。
两个人进入同一个对话，里面住着一只 AI Agent “小章鱼”。它可以插话、记事、查资料、替不好开口的人传个话，也可以保持安静。和那些试图成为朋友、恋人的AI不同， Twoo 是去参与两个真人的相处。
主打“AI+社交”不算什么新鲜事，但目前市面上的多数产品是在用AI代理人、或AI充当社交对象的思路。 Twoo 的思路是，用AI来服务人与人之间的社交关系。
这是我有点难理解 Twoo 的地方：看起来它像是个加入了AI元素的IM，但人和人交流这件事为什么需要AI？况且IM，不就是大厂掌控已久、十年都没什么新产品的领域。
从 Twoo 团队给我看的数据，产品上线约三个月，DAU超6万。新用户次日留存率为68%，30日留存率为23%。在普遍留不住人的AI应用里，这个数字似乎还不错。
今年的7月到10月，我和 Twoo 的创始人陈曦聊了几次，始终围绕这个问题：为什么两个人之间需要一个AI？

## 1

Twoo 7月刚上线时，有组高频用户是一对一起写小说的夫妻。
之前，他俩分别和 GPT 一起写作，各自写完一段再把成果发给对方看。对方评论完，再把反馈贴回 GPT 。而当他们在 Twoo 里做这件事时，AI生成一段情节，一个人说“往这个方向走”，另一个人说出自己的想法、更新设定，创作就这样继续。
但在不聊创作的时候，他们会在 Twoo 里聊很多生活日常。比如给孩子选什么样的学校、需要准备哪些资料，下个月搬家要处理什么，当天有哪些事不能忘。 Twoo 里有个AI小章鱼，负责记忆、提醒、接话等等。
陈曦把这类需求叫作“普通人的琐事调度”。
普通人生活里的事往往是零碎、持续和与不同人交织在一起的。陈曦说，人们很少意识到，生活里很多事都是包含着协作的：买菜的人要兼顾家里所有人的饮食需求；提醒老人吃药的往往是子女；接孩子放学前夫妻间得对一下彼此时间；孩子的学习计划往往来自父母的安排。
我和xiaohan的减肥岛
最典型的例子是旅行攻略。
但凡不是一个人旅行，做攻略的人就需要收集同行者的预算和意见，去找攻略、问AI、做取舍，最后把结果发回群里。新的要求还得重新修改。 Twoo 试着让这个过程直接发生在聊天里：两个人讨论，小章鱼参与补充，形成方案后记进共同的“小本本”。
到了机场，想不起航站楼、登机口，直接问。临时换了行程，让它修改，彼此都能看到，不必再找哪个文件才是最终版。
Twoo 最早也是从琐事里诞生的。
一开始，陈曦在飞书上给自己做了个 AI bot ，帮忙打理生活琐事。但马上遇到了问题，很多事不只影响自己一个人，比如一起吃饭，既要遵守自己的营养计划，又得顾及其他人的口味。他就得在AI和朋友之间来回截图发消息。
实在太麻烦，他干脆在飞书里拉了好几个“两人+bot”的群，以后有事要和这些人商量，就直接拉着bot一起讨论。他给bot设了很高的自由度，可以随意插话，但不能透露别的群里聊的信息。
慢慢地，陈曦发现原本发生在微信里的对话开始往这些群里迁徙。这让他看到了一种可能：AI不必从零建立一段关系，也可以参与到一段已有的关系中。

## 2

Twoo 上没有标准玩法。不同关系的人，把小章鱼用成了不同的东西。其核心是，因为有另一个人在场，使用AI就有了不同的意义。
有个用户曾对陈曦说， Twoo 对于他的价值在于“在对方在场的情况下，用AI查东西”。查“附近有什么好吃的”、“周末有什么展览”，其实在表达的是，“我想跟你一起去”。
用 Personal Agent 给自己设置“记得吃药”，是管理日程；而在 Twoo 里给妈妈设同一个提醒，则更多了一层表达关心。
这当然不是在预设用户在使用 Twoo 之前，每个人都得先有一份“情感表达”。很多时候，只是觉得某个功能顺手，后来发现，心底的一些话在这个对话里、用另一种方式更容易说出来。
在一些对话里，小章鱼还承担着另一个功能。对方发来消息，如果在忙，原来的对话可能就停在那里。但在 Twoo 里，小章鱼会先回应。有时看到了消息，如果你不知道该怎么回，它会递一个台阶。
身处一段关系中的AI到底是什么？
助手、宠物、信使、话题生成机、缓冲带，都对，也不全对。陈曦给小章鱼的定义是：七分功能价值，三分情绪价值。
“如果没有那三分情绪价值，就不会用它了。”
根据 Twoo 最新的数据统计，新用户第一个24小时内设置提醒、打开小本本的比例分别为52%和36%。完成其中任一行为的用户，30日留存约为未完成者的三倍。

## 3

然而， Twoo 上线后面临最大的问题，倒不是小章鱼有没有发挥作用，而是如何找到一起用 Twoo 的人。伴侣、闺蜜容易想到，再往普通朋友扩展就不容易了。
陈曦告诉我，通过 Twoo 号和邀请链接发出的好友申请，通过率高于95%。但这个数字只描述已经发出的申请。难的是发出之前，用户得先猜，对方会不会愿意。
有一些人自己找到了办法。他们去小红书发帖，找陌生人一起用 Twoo 、养小章鱼。不一定是先对某个人产生了兴趣，也可能只是想试试这个产品，需要另一个人配合。
这些行为推动团队做了“码头”，让用户可以在 Twoo 里找到一起“登岛”的同路人。
熟人是 Twoo 最自然的起点，但熟人未必有同样的兴趣。伴侣可能不玩同一款游戏，最好的朋友也不一定同时备考。没有哪一段关系，能够承担一个人全部的相处需求。
于是，码头里出现了备考四六级、减肥、戒烟，甚至是每天喝8杯水的搭子需求。两个人互相督促，小章鱼帮忙列计划、定时提醒。谁也不必一直承担催促对方的责任，也不需要在认识之初，就想好这段关系会走多远。
一个从亲密关系出发的AI应用出现了陌生人社交，这合适吗？
在陈曦看来，更年轻一代的用户不是先定义“我们是什么关系”，再决定可以一起做什么。很多时候是反过来，先有一件想做的事，再去找一个人。
他认为，当AI能给到足够充足的知识和能力之后，人与人的关系反而会回归更纯粹的关系本身。
7月第一次听陈曦说 Twoo 要服务于经营一段关系时，我问他：“这会不会是一种好学生才会有的意识和需求？”等两个月后再见他时， Twoo 上已经有了好多用户们因不同兴趣和任务而设的码头。这与最初那个AI参与的夫妻群已经很不一样了。
接下来的问题是，这些是否足以让两个人离开微信，换一个聊天窗口？

## 4

“用户用 Twoo ，吃掉的不是他们用微信的时长，而是豆包的时长。”
第一次听陈曦讲这句话，我觉得他有点狂。但随着他进一步说明，我才意识到不是在对标。
“触发我们问豆包的往往是和别人的对话。你和谁约了饭，才会去查餐厅；你和谁计划出门，才会去查天气；你们一起聊到了某个话题，你才会去查资料。”他觉得，需求是在关系里长出来的。“只是过去，我们得先切出和人的对话，再掉头去单独问AI。” Twoo 想把这一步放在对话里面。
我后来意识到，除了这种便利和微妙之外， Twoo 有很重要的一部分是在解决AI产品如何获取上下文的问题。
个人 Agent 通过打通日历、邮箱等来建立对个人的认知和记忆，办公 Agent 则通过介入各类文档和知识库来完整工作的上下文。而 Twoo 获取上下文的来源是让小章鱼处在两人持续发生的对话里。
Twoo 的对话界面中，用户可以点击一个禁止按钮就让小章鱼噤声。
据陈曦的观察，一些拥有多个小岛的用户，会先关闭小章鱼的自由插话，却继续在这里聊天。他的理解是，用户未必需要AI一直回应，但希望信息留在这里，需要时不用重新解释。
这也解释了一个有些固执的限制：从亲密关系到陌生搭子， Twoo 的用途不断扩展，岛上却始终只允许两个人。
为什么不更多人？陈曦计算过，两个人之间是一条边，三个人就是三条边，六个人是十五条边。“今天的模型在多人群中无法清晰定义目标，也很难做到让群里的多个人同时满意。”
更麻烦的是注意力问题。两个人说话，目标天然对齐，AI服务这一个目标就好。而人一多，AI回应谁，剩下的人就成了局外人，AI立刻会从帮手变成噪音。这显然不利于上下文的有效积累。
当然， AI Agent 在多人群里也会有其价值，只是 Twoo 目前选择先处理一个更小的单元。
然后的问题是，微信哪天把AI助手嵌入对话了呢？
陈曦也觉得微信、小红书、字节都有可能做这件事。而他认为 Twoo 的机会在于，“有聊天记录”和“用户愿意把这些交给AI”，是两回事。
有一些用户明确对他表示过，不愿意让AI直接读取原有对话。但从一个新窗口开始，用户至少第一天就会知道，这里的聊天会有AI参与。

## 5

陈曦大学读数学，2010年从芝加哥大学毕业后，第一份工作在华尔街做量化交易。
2015年，他回国创办男装订阅平台垂衣：用户提交需求，平台寄来搭配好的衣服，喜欢的留下，不喜欢的退回。垂衣融资到B轮，最终没能做下去。此后，他在阿里和字节工作过，直到今年开始了这段创业。
比起量化训练，上一次创业对他的影响可能更直接。
垂衣团队一度有四百多人。陈曦回忆，团队突然扩大，很多人之间没有信任基础，他开始想维持一个“厉害的CEO”的形象。公司遇到困难时，别人仍愿意跟着自己干，又让他觉得不能辜负。但愧疚、讨好和伪装，都很难成为长期合作关系的基础。
这一次，他更希望团队彼此能直接说话。创业 Twoo ，得实现“过程和结果都得开心”。
陈曦说，他受奈飞文化中“ Context, not control ”的影响很深。 Twoo 团队开会留下所有逐字稿，把共同讨论交给AI，再基于同一份背景推进工作。
“团队不知道而只有合伙人知道的事，只有1%。”
这背后有他自己的一套认识论。陈曦对我说，他觉得人逼近真相只有两种办法：要么反复做实验；要么借助更高维度的工具——好比没有磁铁，人感受不到磁场。在他看来，大语言模型属于后者。“人和人的对话，是一段高维关系投下来的低维影子，而模型能看见人看不见的关联。”
照这个说法，小章鱼就是他放进一段关系里的磁铁。\~\~
\~\~
这当然不能解释成 Twoo 的缘起，却让我更容易理解，为什么陈曦会做 Twoo 。“大量的关系不是死于冲突，是死于维系成本过高。”这句话他对我说过好几次。
不过，陈曦的这种产品理念，的确不是很多人可以理解，有些投资人向他提了许多挑战性的问题。
9月我再见到陈曦时，他已经不太想去证明“所有人都需要 Twoo ”了。他说，选择这个产品的人，本就是认可AI以这种方式参与关系的人。就像不同的人会选不同的协作工具，不必先争出唯一正确的那一个。
过去几个月里，想往这个方向走的也不只有 Twoo 一家。
10月19日， Replika 创始人 Eugenia Kuyda 的新产品 Wabi 向用户开放。这位做了十年AI陪伴的创业者的新产品形态像一个聊天软件，几个人在同一个对话里，AI可以帮忙盯着学校的表格、家里的日程这些琐事。这个“多人共用的AI助理”的想法和 Twoo 有很相似的部分。
有次快聊完时，陈曦提起的一个细节。他发现，有些用户每天打开 Twoo ，不说“在吗”，而说“来领贝壳啦”。贝壳是产品里的虚拟货币，领完之后，两个人往往会接着聊下去。
“在吗”没人回，发的人会有点受伤；“来领贝壳”没人回，还能自我安慰——对方只是对贝壳不感兴趣。小章鱼和贝壳，替犹豫留了点余地。
这可能依然不足以回答，为什么两个人之间需要一个AI。但可能表明， Personal Agent 指向的个人需求，未必只关于一个人。
