# 时文两则 · 王虹专题：挂谷猜想 × 选专业

> 一句话：一篇讲「一个人怎么在无人区里慢慢走出来」，一篇讲「选专业别被热门窄化热爱」——合起来回答 M8 的核心问题：**成长是听从内心、长期深耕，还是追逐外部的热度与标准？**

## 第一则 · M8｜王的猜想（人物特写）

**核心事实**：中国数学家**王虹**与**邓煜**合作证明三维**挂谷猜想**（Kakeya conjecture：「让一根没有厚度的『针』刺透所有方向，究竟需要多少空间」），困扰国际数学界百年；2026 年获**菲尔兹奖**。从广西山村、普通教师家庭走出，求学路上转专业、自我怀疑，最终在数学中建立信心。

**可迁移角度**

| 角度 | 怎么论证 | 可用细节 |
|---|---|---|
| **慢慢来 / 长期主义** | 成长不比快慢，「只要最终有所得，花多长时间并不重要」 | 母亲赠言「别着急，慢慢来」；她把成功归于「个人积累＋合作＋恰好在合适时间遇到合适工具」 |
| **听从内心 / 热爱** | 转专业、选方向都跟着兴趣走，不为热门 | 因对原专业兴趣不浓而转数学；「数学是我理解世界的一种方式」 |
| **非刷题 / 独立思考** | 她并非「典型小镇做题家」——不动脑的重复刷题不适合自己 | 桂林中学首年年级百名外、高二进前十；物理老师评「解题路子野」，超纲自学、「不停地问，然后试图自己回答」 |
| **文理交融** | 数学与文学不矛盾，理性也可有诗意 | 高二作文《数学之美》，大多数人套应试模式，她把数学写进作文，老师评「完全吻合，令人震撼」 |
| **逆境与韧性** | 从「感觉一直在扑空」到信心一点点建立 | 难题攻关期自我怀疑；「随着问题难度逐步增加，她的信心一点点建立起来」 |
| **打破刻板印象** | 女性数学家、非刷题的书呆子形象被颠覆 | 中国籍数学家首次获菲尔兹奖；老师评「有种种和年龄不相称的沉静」，课堂专注、爱在花木中散步让头脑清醒 |

**金句（可直接抄，原文照录）**

- 「别着急，慢慢来。」——母亲赠言，也是全文题眼
- 「只要最终有所得，花多长时间并不重要。也许别人快点，你慢一点，真的没关系。」
- 「让一根没有厚度的『针』刺透所有方向，究竟需要多少空间。」——挂谷猜想，可引申对未知的探索
- 「数学是我理解世界的一种方式。」
- 「数字不会骗人。」——理性、确定、真诚
- 「在数学世界里，我可以自由建造任何东西，不需要向任何人请求。」——精神自由与独立人格
- 「随着问题难度逐步增加，她的信心一点点建立起来。」
- 「王虹与邓煜的故事，不仅是个人的登顶，更是一个国家数学实力从量变走向质变的集体叙事。」——个人与时代勾连

**焊接句示范（素材后面必须有论证，不能贴标签）**

> 写「慢慢来」时：王虹的价值不在「熬了多少年」，而在她把「别人快、我慢也没关系」变成了对节奏的主动选择——慢不是迟钝，是不肯用别人的刻度丈量自己的路。

## 第二则 · M8/M9｜选专业，别因「热门」窄化「热爱」（人民日报评论）

**总论点**：把「热门专业」与「热爱」对立起来，恰恰窄化了成长的空间；**热度由供求决定，不由个人禀赋决定**。

**分论点骨架**

1. **破「追热门」**：热度是市场供求的瞬时信号，拿它当成一生的方向，是把外部标准当成内部热爱。
2. **立基础学科**：数理化、生命科学等基础学科，是破解「卡脖子」难题的底层逻辑；文学、历史、哲学等人文社科与艺术，是人工智能时代仍需的人文素养——它们「或许没有『新』的光环，却事关长期稳定的发展需求」。
3. **立交叉与实践**：专业设置回应社会需求（如法律英语培养复合人才）；「机器人智造专业直接把部分课程搬到车间」，因为「真实问题是复杂的、综合的，应对这些问题的能力，恰恰需要在实践中练就」。
4. **落到人**：选专业应兼顾国家需求、个人禀赋与热爱，不被短期热度窄化长远空间。

**事实弹药**：2026 年新增具身智能、脑机科学与技术、海洋新能源技术与无人技术等 **38 个本科新专业**；教育部《职业教育专业目录》增补 22 个职业本科新专业。

**金句（照录）**

- 热度由供求决定，不由个人禀赋决定。
- 把「热门专业」与「热爱」对立起来，恰恰窄化了成长的空间。
- 数理化、生命科学等基础学科，是破解「卡脖子」难题的底层逻辑。
- 真实问题是复杂的、综合的，而应对这些问题的能力素养，恰恰需要在实践中练就。

## 两篇合用的万能句

> 选专业别追风口，成长别比速度——热度是别人给的刻度，热爱才是自己的罗盘；把「别着急，慢慢来」的定力，用在真正喜欢又于国有用的事上，慢也会走到远处。
