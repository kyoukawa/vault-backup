# images/

批阅单页面与 `.pages` 预览图的归档位置。

**2026-11-07 现状：本目录为空。** 11.02 磁盘事故后图片未随文字恢复，`corpus/01~03` 里的
语料里的批阅单图片引用仍是断链。

## 怎么补

原件都在 iCloud/Files 的 `Note/语文/<题目>/`（只读扫描，不搬原件）：

| 目标路径 | 来源 |
|---|---|
| `images/第二次呼吸/批阅单-1.jpg`、`-2.jpg` | `《第二次呼吸》二稿批阅单（姜川）20260927.pdf` 转图 |
| `images/说论辩/二稿反馈-1.jpg`、`-2.jpg` | `《说论辩》二稿批阅单（姜川）20261026.pdf` 转图 |
| `images/说迭代/批阅单-1.jpg`、`-2.jpg` | `《说迭代》二稿批阅单（姜川）20261011.pdf` 转图 |

- PDF 转图：`pdftoppm -r 150 -png 批阅单.pdf 批阅单`（需要 `apk add poppler-utils`）
- `.pages` 的正文在 `preview.jpg`（zip 解压即得），可用 `apple-vision ocr --source preview.jpg` 转文字
- 文件名必须与语料里的引用**完全一致**，放回去链接自动生效，不用改语料

## 命名约定

`images/<题目>/<用途>-<页码>.<jpg|png>`，题目与 `corpus/` 编号对应，不加日期前缀。
