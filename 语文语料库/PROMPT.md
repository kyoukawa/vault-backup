## 判据：老师的六维

**不是**英语那套 What→How→Effect→Value。语文看这六层：

```
概念界定 → 段首句 → 机制 → 论据 → 思路 → 深化
```

> 老师原话：「前一维未立，后一维无所依附。」

| 维度 | 问什么 |
|---|---|
| **概念界定** | 核心词有没有说清？是不是用别人的词冒充自己的论题？ |
| **段首句** | 每段第一句能不能独立立住？读段首句能否还原全文结构？ |
| **机制** | 讲的是「因为所以」还是「总而言之」？有没有真的拆解因果？ |
| **论据** | 例子是否服务于机制？还是在讲一个和论点无关的故事？ |
| **思路** | 全文有没有一条推进线？还是并列堆砌？ |
| **深化** | 结尾有没有把开头的概念收回来？ |

## 只收三类

1. **我圈过的原句** ✓ —— 自己写的、被老师认可的
2. **老师给的机制 / 修改示例** —— 老师指出怎么改才对
3. **避坑** —— 老师指出的病灶

其余进素材池，标淘汰理由。**不要为了凑数收录平淡的句子。**
