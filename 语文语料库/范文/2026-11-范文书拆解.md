## 题一：他塑与自塑（两篇同题范文对照）

题干核心：淄博烧烤等地方名片走红，离不开「自我与他人的共同塑造」；请以「他塑与自塑」为题写议论文。

### 两篇骨架对照

| 环节 | 例文66 | 例文67（于斯涵） |
|---|---|---|
| 概念界定 | 自塑是对自身价值的挖掘与展示，是他塑的前提和基础 | 内因是外因的作用条件；自塑是他塑的起点 |
| 层次一 | 自塑是他塑的前提：无实际价值，外在塑造终是「空中楼阁，一触即破」 | 他塑的价值：放大已有自塑成果、弥补视角局限——「他塑便是那风，让长出翅膀的蝴蝶飞得更高更远」 |
| 层次二 | 他塑助自塑：更大范围的传播（例文此处 OCR 残缺） | 自塑是主要力量：内因决定发展；淄博因文旅局与店主「用心待客」才在流量后留住人 |
| 层次三 | 警惕过度关注他塑、忽视内在价值（「空中楼阁」反面） | 给自塑加限定条件：立足自身特色、能力所及，不为迎合他塑而矫饰；举行政限价、停车失公的反面 |
| 收束 | 提升自身价值才是根本 | 自由意志、主动展现、灵活平衡，是他塑作用于自塑的前提 |

### 可迁移招法

1. **先立「前提—助力」关系，再加「限定条件」两段式**：例文67 的「他塑有价值 → 但自塑才是起点 → 且自塑须立足自身」是标准的**递进三层**，比并列好用。
2. **比喻绑定论点**：把抽象关系锚到一个意象（风与蝴蝶 / 种子与土壤），后文回扣都借这个意象，首尾自然圆合。
3. **反面素材要落到「失度」而非「全盘否定」**：例文67 批的是「为迎合他塑而矫饰」，不是否定他塑——这种「给对方划边界」的写法显思辨。
4. 两篇共用淄博烧烤、洪崖洞，但都**先给机制再举例**，例子不是贴标签。

## 题二：昨日之我与今日之我（例文71，797字）

题干三种说法：今日源自昨日 / 今日须打破昨日 / 今日可能回归昨日——要求谈对个人成长、社会发展、文明赓续的启发。

### 六维拆解

| 维度 | 这篇怎么做 |
|---|---|
| 概念界定 | 「人是无时无刻不在成长的」起笔，把「我」落在**变化**上；首尾以「影子」「伙伴」喻昨日之我 |
| 段首句 | 三层段首可独立成文：①「人是不能否认自己的过去的」②「昨日之我也不该成为今日之我的枷锁」③「以今日我之姿态，与昨日之我和解」 |
| 机制 | 正反合三层：不能否认过去（立）→ 不能囿于过去（破）→ 与过去和解（合），每层的因果都拆开了 |
| 论据 | 引用：士别三日、《六国论》「抱薪救火」、以史为镜、曾子三省、杨绛「让灵魂也戴上厚重的行囊」；现实：年轻人「给自己办葬礼」；课文活用：清政府割地赔款续六国破灭之路 |
| 思路 | 提问（「以过去之己为耻……这也是可以的吗？」）→ 立 → 破 → 合 → 呼告，正反合推进线清晰 |
| 深化 | 结尾「以昨日之我成就今日之我，以今日之身回顾昨日之误」对举点题；再把「包袱」翻转成「相互扶持的伙伴」，意象回扣第③层 |

### 可迁移招法

1. **正反合三层段首句就是骨架**：面对「A 与 B 关系」题，直接套「不能没有 A → 但 A 不该成为束缚 → 与 A 和解/共生」。
2. **问句树靶开篇**：「有人……以过去之己为耻，这也是可以的吗？」——先摆现象再反问，比直接下定义更有张力。
3. **课文素材一材两用**：《六国论》「抱薪救火」原本讲割地事秦，这里反用为「正视昨日之我」的论据，再接清政府现实延伸——把熟素材换一个论点重接，是本页评语点名的「活用课文素材」。
4. **翻转式收尾句**：「……不是沉重的包袱，是前行路上相互扶持的伙伴」——「不是 X，是 Y」把否定与肯定合一体，形象又有力。
5. **呼告 + 第二人称**：「朋友们，请善待自己的影子」「和过去的你说一声再见」，兼顾评语说的「理性思辨又形象精警」。

## 老师评语要点（例文71）

> 「非常切合题目，对两者关系有深入思考且阐释到位，能基于两者关系谈对生命的认识；论证层层递进，逻辑谨严，说理意识强；立足现实、有针对性；语言富于理性思辨又形象精警；既能活用课文素材，又有开阔视野。」

## 同题第二篇：例文72（p78）

**骨架（与例文71 同题，对照看）**

| 环节 | 例文71 | 例文72 |
|---|---|---|
| 立论角度 | 正反合：不能否认→不能囿于→和解 | 三层递进：**底色 → 改造 → 接受** |
| 第一层 | 不能否认过去（以史为镜、六国论） | 昨日之我是今日之我的**底色**（迟子建：东北乡情与少年想象造就作品气质） |
| 第二层 | 不该成为枷锁（给自己办葬礼） | 发挥**主观能动性**改造昨日之我（戒烟屡败屡战、鲁迅弃医从文） |
| 第三层 | 与昨我和解（曾子三省、杨绛） | **接受**昨日之我、成就今日之我，不必全盘否定（马克思「前途光明、道路曲折」） |
| 收束 | 以昨我成就今我；包袱→伙伴 | 以昨我为基石＋主观能动性，成就更好的今我 |

**两篇评语的差别最值钱**：例文71 被赞「能基于两者关系谈**对生命的认识**」；例文72 却「对生命成长的认识，思考**还可以更深入**」。同为切题、说理清楚，差就差在**最后一步有没有把关系升到生命/普遍层面**——这正是「深化」那一维的分数点。

**可迁移招法**：「底色 → 能动改造 → 接受成就」又一套 A/B 关系三段式，可与例文71 的「不能没有→不能囿于→和解」二选一；迟子建、鲁迅弃医从文是可复用的论据。
