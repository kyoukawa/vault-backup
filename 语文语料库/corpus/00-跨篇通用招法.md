# 跨篇通用招法与批改口径 2026.10.27

> 相当于英语库的 `00-跨主题句式库`。
> 来源：三篇批阅单里**反复出现**的判词。只在不同篇目都出现过的才收，避免臆造。
> 依赖次序：概念界定 → 段首句 → 机制 → 论据 → 思路 → 深化。**前一维未立，后一维无所依附。**

---

## 一、老师的六个判据维度（判分顺序）

| 维 | 老师要什么 | 我的落地检查 |
|---|---|---|
| ① 概念界定 | 拆要素，且**每要素配一句反证** | 「迭代」要三要素；「论辩」要「交换」——要素没拆开就是空 |
| ② 段首句 | 立本段方向，**与下一段尺度不同、不重复** | 「理清自己的想法」vs「提供新视角」，一内一外 |
| ③ 机制 | **回答「为什么/怎么来的」**，不是断言 | 「被迫」要落到动作上；「短板」要说出从哪儿来 |
| ④ 论据 | 写实，且**必须与论点一一咬合** | 华为要写「哪一处、上一代改了什么」 |
| ⑤ 思路 | 给读者一条走得通的路 | 先对齐定义 → 再摆理由 → 再检验视角 |
| ⑥ 深化 | 把「为什么还需要它」讲到底 | ④⑤不能都在讲同一件事 |

## 二、七类高频病灶（我这边反复出现的）

### 1. 题眼未对接

以「我认为的核心词」替代题目给定的核心词。

- 《说迭代》：「空有改进与优化并不足以称之为迭代」→ 必须让题目词在句内正面出现
- 《说迭代》：「先有清晰目标再一步步前进」→ 题眼从「在原有基础上改」被换成「先有目标再行动」
- 《说论辩》一稿：①界定停在「立场都需要支撑」，没界定「交换」

> **自检一句话**：这半句能不能原样贴到别的题上也成立？能，就说明它没咬住题目。

### 2. 机制缺一句

写了好处，没写好处**怎么来的**。

- 《说论辩》②「被迫重新审视」——被迫从何而来？
- 《说迭代》②③「短板从哪儿来」「目标该定多高」

> **补法（老师给的模板）**：**「话一说出口，就得一句接一句地排下去；排到某处接不上，那一处便是自己原先含混带过的地方。」**
> ——把抽象关系换成**一个具体动作**。

### 3. 段与段功能重叠

两段都在讲同一句话的两面。

- 《说论辩》④⑤都在讲「只论立场不论理由」→ 合并，或⑤专论「复述」这条判据
- 判分后果：占字数，不占分

### 4. 一套话里两个指代 / 因果被埋

- 「它的本质……以华为为例，它在通信技术上」——两个「它」其实两个人
- 「理想与现实相差太远，人便觉得微少努力无济于事，期望过高，反而看不见正反馈」——四个分句一口气排下来，因果埋了

> **改法（老师原文）**：「原因是，目标定得太远：离得太远，每一步都显得微不足道，人就看不见自己确实是在往前挪。」

### 5. 首尾不回扣（来自《第二次呼吸》）

① 段拆过几个要素，收尾/升华段**没把它们原样收回**。

- 《第二次呼吸》：① 已点明「新阶段不等于极点前的轻松，而是并不轻松但稳定的可控状态」，④ 只写「到达新阶段 / 文明跃迁的机遇」，**没回扣**「并不轻松」这层 → 老师判「与①的设定略断」
- 补法：在「到达新阶段」后加半句 **「这新阶段并非轻松如初，而是更稳可控的跃迁——第二次呼吸是跃升，不是恢复旧我」**

> 这是**升档最多的一处**（48 → 49 的核心建议）。**开头挖的坑，结尾必须填上。**

### 6. 「说开去」只有号召，没有落点

升华段写成「我们应该像……一样」，后面没有今天的人/事。

- 《第二次呼吸》⑤「我们应该像革命先辈一样：激发斗志……调整节奏……」——判「从『号召』变『论证』，需补一句实据」
- 补法：接一句当代案例（如某企业核心部件断供后转向自主研发，于压力中开出新局）

> 口号谁都会喊，**加一个今天的具体名字，才是论证。**

### 7. 论据写「地名」不写「困境」

- 一稿④：「长征、到遵义会议、延安革命根据地，从星星之火到燎原之势」——**地名不是困境**
- 二稿：「左倾教条主义路线走到尽头 → 红军到达生死存亡的临界 → 会议上调整路线修正左倾错误 → 理论结合中国道路」
- 老师的话：这才叫「写出『原路走不通』的标准判据」

> **通用三段式**：**哪条路走不通 → 谁在哪里认了错 → 改成了什么。**

## 三、通用框架句（换词即用）

| 功能 | 框架 | 出处 |
|---|---|---|
| 给概念拆要素 | 「X，指……的过程。它的关键要素有三：一是……，二是……，三是……。缺一不可：没有……，……便成空谈」 | 迭代① |
| 划界 | 「论辩不是论战，辩的是理由，不是人」 | 论辩⑤ |
| 对立概念各定其位 | 「真正的X，是在原有基础上校准方向：目标回答『往哪里去』，基础决定『从哪里改』」 | 迭代③ |
| 逆推机制 | 「那一处接不上的地方，便是自己原先含混带过的地方」 | 反馈单修改示例 |
| 摊开两难 | 「没有A，B只是空想；没有B，A又会失去意义」 | 迭代③ |
| 收回三要素式收尾 | 「先把……打好，再在……上轮轮迭代；不完美不是失败，而是下一轮改进的入口」 | 迭代⑤ |
| 抽象密码句（三主体并提） | 「无论个人、政党还是文明，X 的密码都是：当旧方式走向尽头，不是更用力地重复，而是重新决定力气往哪使」 | 第二次呼吸⑥（全篇最亮） |
| 双要素先后 | 「所谓A，正是……；而B，则是在A之后……之时愿意……」 | 第二次呼吸②（双翼一体成型） |

## 四、收尾四条铁律

1. **不以祝愿收尾**（「愿我们……」「希望……」）——一稿病，三篇都被点
2. **压成三句以内，落在判断上**：「先对齐定义，再复述理由，胜负最后」
3. **不与末段最后一句重复**（「论辩才见真理」被判与⑤末句略重，删）
4. **收尾前先回扣开头**：把①拆出的要素原样收回（「第二次呼吸」密码句即此法的满分示范）

## 五、得分层级（从三篇四稿倒推，非老师量表）

| 分 | 状态 | 例子 |
|---|---|---|
| 45–48 | 六维全立、题眼守住、论据写实，差在细节打磨 | 说论辩二稿 45、第二次呼吸 48 |
| 42 | 三维度无硬伤，但机制只补了一半、论据有一处空 | 说迭代 42 |
| 40 | 骨架对，机制/论据有缺口，收尾带祝愿 | 说论辩一稿 40 |
| 38 | 题眼挪走 + 例证不实 | 说迭代一稿 38 |

> 到 45 以上的瓶颈是「**细节**」，40 → 45 的瓶颈是「**机制与论据**」。前者靠打磨，后者靠一句补半句。
