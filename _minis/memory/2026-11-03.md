## 迁移到一加 Android 16（2026-11-03）

从 iOS + iSH 迁到 **一加 PLZ110 / Android 17 (sdk 37) / ColorOS**，Alpine 3.21 PRoot。
硬件：8 核 aarch64，15G 内存，455G 磁盘（余 393G）——比 iSH 强很多。

### 迁移后重建了什么
- 工具链：python3 / git / ripgrep / ffmpeg / curl / yt-dlp / py3-requests
- 两个仓库从 GitHub 克隆回来（`git clone --depth 50` 才成功，普通 clone 会 SSL 断连）
- **从 `vault-backup` 的 `_minis/` 恢复了 MCP 配置和 OAuth 令牌，不用重新授权**
  - 关键：`oauth/Notion.json` 拷回后要 `minis-mcp-cli shutdown` 重启 daemon 才生效
- vault 从备份恢复到 `/var/minis/mounts/dev/TheBook`（22 篇）

### 语音识别的四次尝试（重要）
| 方案 | 结果 | 原因 |
|---|---|---|
| apple-speech | ❌ | iOS 专属 |
| android-speech | ❌ | 这台一加没装系统语音识别服务（ColorOS 无 GMS） |
| faster-whisper | ❌ | ctranslate2 只有 glibc 版，musl 符号缺失（试过 gcompat、LD_PRELOAD、sitecustomize 全失败） |
| **whisper.cpp** | ✅ | 源码编译，`-DCMAKE_BUILD_TYPE=Release`，8 核并行 |

**whisper.cpp 位置**：`/opt/whisper.cpp/build/bin/whisper-cli`（已软链到 /usr/local/bin）
**模型**：`models/ggml-small.bin`（465MB，从 hf-mirror.com 下载，HuggingFace 直连超时）
**性能**：60 秒音频约 14 秒转完，英文准确

### 新增能力
- `transcribe.py` 支持本地音频文件直接转写（m4a/mp3/wav/aac/flac/ogg/amr/3gp/webm）
- 自动选 whispercpp 后端；本地文件默认按中文识别

### 未解决的
- **沙箱看不到手机存储**：`/storage/emulated/0` 在 PRoot 内不存在，需在 Minis 设置里挂载外部文件夹
- **沙箱无 /dev/snd**：ffmpeg 录不了音，用户用系统录音 App 录完发文件过来
- user 选择「录好文件我转」的方案
