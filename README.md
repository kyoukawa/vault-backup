## ⚙️ 维护约定

- **不是代码项目**，是 Obsidian vault 的备份仓库；自动同步靠 obsidian-git，无定时 cron。
- **根目录只放文件夹 + 导航页**；每个库有且只有一个 `INDEX.md`，库里每级导航顶部写 `↑ [[知识库导航|总导航]]`。
- **链接写全 vault 根相对路径**（`[[库/子目录/页名]]`）。只写页名会在 9 个 `INDEX.md` 之间串味。
- **文件名不要带 `[` `]`**（Obsidian 双链解析不了），用 `【】`；表格里的竖线写成 `\|`。
- **教材式索引自动生成**：`试卷库/<年>/<卷别>` 页面由 `workspace/tools/gen_index.py` 扫描目录生成，`做题记录` 的统计块由 `gen_progress.py` 重算 —— 不要手改表格。
- **提取失败的题集废稿**统一放 `试卷库/_待重提取/`（附清单），不参与题集导航、不计入数字化进度。
- **三个导航页的分工**：`知识库导航.md` = Obsidian 权威；`index.html` = 网页首页（动态：进度、在读、入口都在这一页）；`index.md` = 网页目录的 Markdown 版（走 `view.html` 阅读器）；`README.md` = 仓库说明。

### 自检

改完索引后跑一遍断链/孤儿页检查（临时脚本放 `.tmp/`，不入库）：

1. 每个 `.md` 都应有入链，否则是孤儿页；
2. 每个 `INDEX.md` 顶部有 ↑ 回总导航；
3. `assets/ids.json` 里的路径都真实存在；新增常用页补一条 ID，其余交给 `view.html?file=<路径>` 兜底；
4. `assets/linkmap.json` 由 `.tmp/gen_linkmap.py` 全量重生成（重名 basename 不建短键，避免 INDEX 串味）。
