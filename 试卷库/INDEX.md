## 维护约定

- **新增卷子**：放 `试卷库/<年>/<卷别>/<学科>/<卷名>.pdf`，卷别用 一模 / 二模 / 期中 / 期末 / 真题。放完重跑索引生成脚本（下面）。
- **提取失败的题集**：统一放 `试卷库/_待重提取/`（附 README 清单），不参与导航、不计入数字化进度。
- **索引自动生成**：各年份页面由 `workspace/tools/gen_index.py` 扫描目录产出，**不要手改表格**；改完目录重跑脚本。
- **批量拉取**：`python3 ~/minis/skills/gx-question-bank/scripts/qbank.py paper ...`，配合 `https://ti.gxwtf.cn/api/test-paper/<id>/pdf`（免登录）。
- **下载后核对 `Content-Length`**：网络中断会留下头部合法但被截断的 PDF。
